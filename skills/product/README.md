## アイデア出し用（外部から取得。本体は改変していない）

取得元・コミット・ライセンスは各フォルダの `SOURCE.md`。使う前に SKILL.md を読むこと。一覧とおすすめは [`ideation-skills-2026-10-20.md`](ideation-skills-2026-10-20.md)（導入方法・利用の注意点つき）。

| スキル | いつ使うか |
|---|---|
| [`generative-thinking/`](generative-thinking/SKILL.md) | 案が似たり寄ったりのとき。発想の型を1つ選んで実行する（ユニークさ重視） |
| [`oblique/`](oblique/SKILL.md) | ランダムな発想カードで偶然の刺激がほしいとき |
| [`ideation/`](ideation/SKILL.md) | SCAMPER など手法の選び方から任せたいとき |
| [`brainstorming/`](brainstorming/SKILL.md) | 質問を重ねて課題を絞り込み、2〜3案を比べるとき（Superpowers） |
| [`lateral-think/`](lateral-think/SKILL.md) | 前提を疑い、視点を変えたいとき（水平思考） |
| [`jwynia-brainstorming/`](jwynia-brainstorming/SKILL.md) | 行き詰まりの原因から探したいとき |
| [`bmad-brainstorming/`](bmad-brainstorming/SKILL.md) | チームの発想会を進行したいとき |
| [`brainstorming-research-ideas/`](brainstorming-research-ideas/SKILL.md) | 調査寄りの発想（10種のフレームワーク） |
| [`thought-patterns/`](thought-patterns/SKILL.md) | 発散・水平・連想・類推のパターンに振り分けたいとき |
