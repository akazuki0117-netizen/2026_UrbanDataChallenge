「優先度 高」の定義は「新規アプリ余地が○で、かつNEC評価が高」。空き家は両方とも満たしていない。そこで今日は、各列を「アプリがその評価を裏づけたか、引き上げたか」という問いに置き換えて見ていく。

    前提の共有

    • 今日の判定の仕方：列ごとに「選定時の値 → 今日の判定」を付ける
  2. 0:0510分

    デモ

    • 所有者の登録（マイナンバーカードでの本人確認）→ 間取り・状態の入力 → 見積

    • 見る人は「どこが既存サービスと違うか」をメモしておく
  3. 0:1520分

    新規アプリ余地（△ → ?）：主役を決める

    • チームの分析では、マッチング（C09）は主な原因ではないという結果。詰まりは「売りに出す前」にある（売却用の空き家は約100戸なのに取引は年79件。空き家バンクの充実を求める声は2%）
    • アプリの中心にある時間貸し・予約の即確定は、マッチングの機能 → 自分たちの分析と食い違う
    • 一方で、登録から見積・市の審査までの流れは「売りに出す前」の詰まりに効く
    • 決めること：主役は「売る前の登録と見立て」か「時間貸し」か。時間貸しを残すなら、どういう位置づけにするか
  4. 0:3510分

    既存サービスとの違い（▲）・NEC評価（中 → ?）

    • 問い：時間貸しだけなら、akippa やスペースマーケットなど既存サービスで足りる。既存にない部分を1文で言えるか（本人確認／市の台帳に載る／売る前に相場が分かる）
    • 価格モデル：学習は135件。2025〜26年の50件を当てたとき、±20%以内が52%、誤差の中央値は18.5%。50%の幅は予測の×0.83〜×1.20。戸建てだけで、調整区域のデータは0件
    • 問い：この精度で「AI活用」と言えるか。「査定の代わりにはならない目安」であることを、画面でどう見せるか
  5. 0:4510分

    市・ニッポン放送の評価、9/21の宿題

    • 市（高を維持できるか）：審査は1件に何分かかり、年に何件を見込むか。空き家バンクや空家等対策計画のどこを置き換え、どこを補うか
    • ニッポン放送（中 → ?）：ラジオで何を呼びかけるか（例：「相続したら、まず登録を」）

    • 流れが一方通行で循環しない9/21：登録 → 審査 → 活用 → 次の所有者、とつながるようになったか
    • 工程間の接続9/21：登録（REG）→ 台帳（LDG）→ 活用（USE）の状態の受け渡しが要件に書かれたか
