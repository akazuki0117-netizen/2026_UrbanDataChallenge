# skills/meeting/ — 会議用

会議の前後のスキルを置く。

## スキル一覧

| スキル | いつ使うか |
|---|---|
| [`gijiroku/`](gijiroku/SKILL.md) | 議事録を書くとき（OneNote の写真・トランスクリプト・サマリから） |
| [`agenda/`](agenda/SKILL.md) | 決めることがある会議の前に、アジェンダ・進行表と判定シートを作るとき |

## 入れる予定のもの（例）

- アジェンダ・進行表（判定シートつき）
- 議事録（トランスクリプト・OneNote から。`meeting/` の形式）
- レビュー資料（アプリ概要・操作概要・スイムレーン）
