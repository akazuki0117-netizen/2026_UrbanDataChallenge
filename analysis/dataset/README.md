# analysis/dataset/ — チームで共有するデータ

アプリと分析で使うオープンデータを、チームで1か所にまとめる場所。各メンバーのフォルダ（`analysis/<GitHubユーザー名>/`）は個人の作業用で、**みんなで使うデータはここに置く。**

## 構成

| フォルダ | 中身 |
|---|---|
| `raw/` | 取ってきたままのデータ。上書き・改変しない |
| `processed/` | `raw/` を整えたデータ。アプリに渡す JSON もここで作る |

`raw/` と `processed/` の中は、データの出どころごとにフォルダを分ける（例：`raw/e-stat/`、`raw/kokkai/`、`raw/e-gov-laws/`）。

## データ一覧

データを足したら、この表に1行足す。

| フォルダ | データ | 提供元 | 取得日 | 利用規約（ライセンス） | 作ったスクリプト |
|---|---|---|---|---|---|
| `processed/chiba/r8_shigan_ratio.csv` | 千葉県 県立高校の学科別の募集人員・志願者確定数・倍率（令和8年度 一般入学者選抜） | [千葉県教育委員会](https://www.pref.chiba.lg.jp/kyouiku/shidou/nyuushi/koukou/r8/r8kakuteiitiran.html) | 2026-11-28 | 県のサイトは無断の複製・転用を禁止。数値（事実）だけを表にし、出典を書く | [`src/fetch/chiba_shigan_ratio.py`](../src/fetch/chiba_shigan_ratio.py) |

## ルール

- **出典と利用規約を必ず書く**（上の表）。規約が分からないデータは置かない
- `raw/` は上書きしない。整えたものは `processed/` に新しく置く
- 加工は手作業ではなく [`../src/`](../src/README.md) のスクリプトで行い、同じ結果をもう一度作れるようにする
- **public リポジトリ**なので、個人情報・API キーを含むデータは置かない（[公開のルール](../../docs/公開のルール.md)）
- 1ファイル 50MB を超えるデータは置かない。取得用のスクリプトだけを置き、データは各自の手元で作る
