## サブフォルダ共通の構成

| ファイル／フォルダ | 内容 |
|---|---|
| **`README.md`** | そのメンバーの分析の要約 |
| **`分析方針.md`** | 分析の目的・原則・現時点の方針。意思決定のたびに更新履歴つきで追記する |
| **`ANALYSIS_LOG.md`** | 分析・調査のたびに書く日誌（何を・なぜ・どう判断したか） |
| `raw/` | 加工前の生データ |
| `processed/` | `raw/` を集計・前処理した後のデータ |
| `figures/` | 分析から作った図・表 |
| `reports/` | 分析結果のレポート・考察 |

## 運用ルール

- 分析・調査をしたら、自分のフォルダの `ANALYSIS_LOG.md` に追記する
- 分析の方針を変えたら、`分析方針.md` の更新履歴に残す（上書きして消さない）
- `raw/` は上書き・改変しない。加工は `processed/` に新しく置く
- 出典（URL・取得日）と、データの利用規約（ライセンス）を必ず残す
- 他人のフォルダのファイルを直接編集しない。参照するときはパスを明記する
