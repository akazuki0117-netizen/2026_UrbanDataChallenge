# analysis/src/ — データの取得・加工のスクリプト

[`../dataset/`](../dataset/README.md) のデータを作るスクリプトを置く場所。チームで共有するコードはここ、個人の試し書きは各メンバーのフォルダに置く。

## 構成

| フォルダ | 中身 |
|---|---|
| `fetch/` | API やサイトからデータを取ってきて `dataset/raw/` に保存する |
| `process/` | `dataset/raw/` を整えて `dataset/processed/` に保存する（アプリ用の JSON を含む） |
| `common/` | 複数のスクリプトで使う関数（パスの指定、API の呼び出しなど） |

## スクリプト一覧

スクリプトを足したら、この表に1行足す。

| スクリプト | やること | 入力 | 出力 | 担当 |
|---|---|---|---|---|
| | | | | |

## ルール

- 1つのスクリプトは1つのことだけをする（取る・整える を分ける）
- 入力と出力のパスはスクリプトの先頭に書き、`dataset/` の外に書き出さない
- **API キーはコードに書かない。** リポジトリの直下の `.env` に書いて読み込む（`.env` は git に載らない。キーの名前だけ `.env.example` に書く）
- 実行方法はスクリプトの先頭のコメントに書く（例：`python analysis/src/fetch/estat_population.py`）
- 使うライブラリを足したら、このフォルダの `requirements.txt` に書く
