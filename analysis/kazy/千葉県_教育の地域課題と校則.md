# 千葉県の教育の地域課題と、校則データの使い道

- 作成：akazuki0117-netizen（11/28 の宿題「千葉県の地域課題リサーチ」）
- 目的：千葉県の教育に、データで示せる地域課題があるかを調べ、校則のデータセットを使える課題を見つける
- 数字はすべて公的な資料から取った。出典は各節の末尾と最後の一覧に書いた

---

## 結論（先に）

1. **校則が不登校の主な理由だ、とはデータでは言えない。** 千葉県の公立高校（全日制）で、不登校の生徒について学校が把握した事実のうち「学校のきまり等」は **1.4%（2,488人中 35人）** しかない。「校則で不登校を減らす」という筋立ては、根拠が弱い
2. **データで一番はっきり見える地域課題は「定員割れ」と「1年生の中退」。**
   - 令和8年度の入試で、**176学科のうち 86学科（49%）が倍率 1.0 倍未満**。学校で見ると **118校のうち 56校**に定員割れの学科がある。**埋まらない席は 1,830席**
   - 中退の **37%は1年生**。1年生の中退率は 1.59% で、2年生（0.99%）・3年生（0.40%）より高い。中退の理由の 55%が「学校生活・学業不適応」
3. **校則のデータが一番生きるのは「入学前に学校の生活ルールが分からない（ミスマッチ）」という課題。** 偏差値と倍率だけで高校を選び、入ってから「合わない」と気づくことが、1年生の中退・不適応や、定員割れの学校の魅力が伝わらない問題につながっている、という筋立てなら、校則・倍率・中退のデータをつなげられる
   - ただし「校則のミスマッチが中退の原因」と言える直接のデータはない。これは**仮説**で、アプリや分析で確かめる対象として出す
4. **県立高校の校則の見直しの状況は、公表されたものが見つからなかった。** 千葉市（市立）は調査結果を出していて、埼玉県は県議会で学校数まで答えている。千葉県（県立）は、全校の校則をサイトに載せている一方で、「どれだけ見直したか」は見えない

## 1. 不登校・中退（令和6年度、千葉県の公立学校）

| 項目 | 千葉県 | 前年度 | メモ |
|---|---|---|---|
| 不登校（小学校） | 6,121人（2.09%） | 5,713人 | 増加 |
| 不登校（中学校） | 8,478人（5.89%） | 8,587人 | ほぼ横ばい |
| 不登校（高校） | **3,178人（3.62%）** | 3,108人 | 全日制 2,488人（2.9%）、定時制 690人（**27.4%**） |
| 高校の中退 | **951人（1.07%）** | 999人 | 全日制 0.87%、定時制 6.59%、通信制 3.81% |
| 全日制の学年別の中退率 | **1年 1.59%**・2年 0.99%・3年 0.40% | | 中退者の 36.8%が1年生 |
| 中退の理由 | ①学校生活・学業不適応 55.0% ②進路変更 26.7% ③学業不振 7.0% | | 進路変更の 45.7%は「別の高校に入りたい」 |
| いじめの認知（全体） | 54,724件 | 54,455件 | 高校は 979件 |

**全国との比較の注意**：千葉県の数字は**公立だけ**、全国（文部科学省）の高校の不登校 1,000人あたり 23.3人（約 2.3%）は**国公私立の合計**。対象が違うので、そのまま比べられない。

### 不登校について学校が把握した事実（高校・全日制、複数回答）

| 順位 | 事実 | 割合 |
|---|---|---|
| 1 | 学校生活に対してやる気が出ない等 | 33.5% |
| 2 | 生活リズムの不調 | 28.8% |
| 3 | 学業の不振 | 15.9% |
| 4 | 不安・抑うつ | 12.3% |
| 5 | いじめ以外の友人関係 | 10.8% |
| … | **学校のきまり等**（制服を着たくない等） | **1.4%** |

これは学校側が把握した事実なので、生徒が本当の理由を学校に言っていない分は入っていない。それでも、校則を不登校の主な理由として出すのは難しい。

## 4. 校則のデータセットを使える課題（候補）

校則のデータは「学校 × 項目のあり／なし」の表と、元のページへのリンクとして作る前提（本文は無断転載禁止なので公開しない）。

| # | 課題（誰の・何を） | つなぐデータ | 校則データの役割 | 強さ |
|---|---|---|---|---|
| A | **中学生と保護者**：偏差値・倍率でしか高校を選べず、入ってから生活のルールが合わないと分かる（1年生の中退・不適応） | 校則の表、志願倍率、中退（県全体） | 学校ごとの「生活のルール」を比べる材料 | ◎ 校則が主役になれる。体験型（学校選び・診断）にしやすい |
| B | **定員割れの学校・県教委**：学校の魅力が伝わらず、半分の学科が埋まらない | 志願倍率（学校別）、校則の表 | 「校則がゆるい・自由な学校は人気か」を分析する | ○ 分析として面白い。ただし偏差値・場所の影響が大きく、因果は言えない |
| C | **中高生（生徒会）**：校則を変えたくても、根拠・他校の例・手順がない | 校則の表、e-Gov 法令 API | 「他校ではどうか」を見せる材料 | ○ 前回の案。地域課題との結びつきは「千葉の校則」だけ |
| D | **県教委・県民**：県立高校で校則の見直しがどれだけ進んだか見えない（千葉市・埼玉県は見えている） | 校則の表（改訂年の記載）、千葉市・埼玉県の数字 | 見直しの状況を県全体で数える | ○ 「見える化」の作品になる。データ・アクティビティ向き |
| E | 不登校の生徒：校則が理由で学校に行けない | 不登校の要因 | — | × 「学校のきまり等」は 1.4%で、データの裏づけが弱い |

**おすすめは A。** B と D を分析の材料として足すと強くなる。

- A の筋立て：「千葉の県立高校の半分の学科が定員割れ。その一方で、入学後の不適応で1年生の中退が多い。偏差値以外の学校の情報、特に毎日の生活のルールが、入学前に比べられないことが一因では」
- 作るもの（例）：中学生が「大事にしたいこと」（髪型の自由、スマホ、アルバイト、制服など）を選ぶと、合う県立高校が倍率・場所と一緒に出てくる。校則の元のページへのリンクつき
- オープンデータ：志願倍率・募集定員（県）、学校の場所（国土数値情報の学校データ）、学校基本調査
- 気をつけること：学校の「ランキング」にしない（学校どうしの競争をあおる心配。11/28 の tmzwx4a-hub の指摘）。校則の評価（良い・悪い）をアプリが決めない

## 5. 校則についての国の動きと、若者・家庭の声（追加の調査）

### 5-1. 国は「入学前に校則を知れるように」と求めている

文部科学省は 2025年7月に、公立中学校・高校の「校則等の見直し状況調査」の結果を出し、各学校に通知した。

| 項目 | 全国の公立中・高 |
|---|---|
| 令和元年度以降に校則を制定・変更した学校 | 約 91% |
| 変更のとき、生徒か保護者の意見を聴いた学校 | 約 85%（約 15%は聴いていない） |
| 校則を変える手続きを定めている学校 | 約 71%（**約 29%は定めていない**） |
| **校則を学校のホームページに載せている学校** | **約 57%** |

通知では、**入学する前の段階を含め、校則の内容と、なぜその決まりがあるのかを知ることができるよう、ホームページなどで示しておくことが適切**としている。2022年12月に改訂した生徒指導提要（こども基本法を受けて校則の記述を増やした）も、校則を絶えず見直すこと、生徒・保護者の意見を聴くこと、手続きを示しておくことを求めている。

→ 千葉県は全県立高校の校則をサイトで公開している（全国では 57%）。**「入学前に校則を知る」ための材料はそろっているのに、中学生が比べて使える形になっていない。** ここが案 A の出番。

### 5-2. 若者の多くは「見直すべき」と考えている

日本財団「18歳意識調査」（2024年3月公表）で、9つの校則それぞれについて「見直すべき」「どちらかというと見直すべき」と答えた合計：

| 校則 | 見直すべき（合計） |
|---|---|
| 特定の髪型を指定・禁止する（男子は丸刈り、など） | **80.2%** |
| 全員がいずれかの部活に入る | 77.1% |
| 靴下の色・長さを指定する | 76.8% |
| 頭髪の色は黒と指定する（地毛でも染め直す） | 76.1% |
| 携帯電話の持ち込みを禁止する | 73.6% |
| 性別ごとの制服を毎日着る | 72.9% |
| パーマ・巻き髪の禁止（地毛は証明を出す） | 71.2% |
| 制服の着方を指定する（スカートはひざ下、など） | 70.8% |
| お菓子など昼食以外の食べ物の持ち込みを禁止する | 67.6% |

女性のほうが全体的に「見直すべき」が多い。→ **校則の表の項目は、この9つを土台にすると、若者の関心とそろう。**

### 5-3. 高校選びの調査に「校則」の項目がない

埼玉県の「県立高校の特色化に向けたアンケート」（2023年12月〜2024年1月、14万人）で、高校選びに「重視する（した）」と答えた割合：

| 観点 | 中学生 | 中学生の保護者 |
|---|---|---|
| 通学の便利さ | 59.6% | 67.4% |
| 授業の難易度 | 52.9% | 40.6% |
| 部活動・学校行事 | 52.2% | 31.0% |
| 設置されている学科・コース | 51.1% | 61.0% |
| 学校の施設・設備 | 48.3% | 33.3% |
| **学校のイメージ・校風** | **48.2%** | **52.1%** |
| 進学・就職の実績 | 41.4% | 54.1% |
| 学費 | — | 61.8% |

**校則・制服・生活のルールは、選択肢に入っていない。** 中学生の約半分が重視する「校風」は、中身があいまいで比べられない。→ 「校風」の中身を、校則の表で具体的に見せられる。行政の調査でも見えていない部分なので、作品の新しさになる。

### 5-4. 案 A を支える根拠のまとめ

| 主張 | 根拠 |
|---|---|
| 千葉の県立高校は、人気が偏って半分の学科が定員割れ | 令和8年度入試、176学科中 86学科が 1.0倍未満（2章） |
| 入学後の不適応で1年生が多く中退している | 中退の 37%が1年生、理由の 55%が学校生活・学業不適応（1章） |
| 国は、入学前に校則を知れるようにすべきとしている | 文部科学省の通知（2025年7月） |
| 若者の7〜8割は、髪型・黒髪・靴下などの校則を見直すべきと考えている | 日本財団 18歳意識調査 |
| 中学生・保護者の約半分は「校風」で高校を選ぶが、その中身（生活のルール）は比べられない | 埼玉県の 14万人調査 |
| 千葉県は全県立高校の校則を公開していて、材料はある | 県の掲載先一覧 |

**言えないこと**：校則が合わないことが中退の原因だ、という直接のデータはない（学校別の中退者数も公表されていない）。作品では「入学前に生活のルールを比べられるようにすれば、ミスマッチを減らせるのでは」という提案として出す。

出典：[文部科学省 校則等の見直し状況調査結果（2025年7月 通知）](https://www.mext.go.jp/content/20250702-mxt_jidou01-000043523_1.pdf)、[生徒指導提要（改訂版）](https://www.mext.go.jp/a_menu/shotou/seitoshidou/1404008_00001.htm)、[日本財団 18歳意識調査（2024年3月）](https://www.nippon-foundation.or.jp/app/uploads/2024/03/new_pr_20240306_04.pdf)（p.12・13）、[埼玉県 県立高校の特色化に向けたアンケート結果](https://www.pref.saitama.lg.jp/documents/254185/060523_h3.pdf)（p.4・6）

## 6. まだ確かめていないこと

- 千葉県議会で校則についての質問・答弁があるか（会議録検索を手で行う）
- 校則の PDF が文字を読み取れる形か、スキャンした画像か（表を作る手間が変わる）
- 学校別の中退者数は公表されていない（県全体の数字のみ）。A の仮説を学校ごとに確かめることはできない
- 偏差値は公的なデータがない（民間のサイトの数字は規約の問題がある）
- 千葉市の校則の調査の数字、県の職業系学科の志願倍率（0.90倍）は、検索結果の要約から取った。元の PDF を開いて確かめる
