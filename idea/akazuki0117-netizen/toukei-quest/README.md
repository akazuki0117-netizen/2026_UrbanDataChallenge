## ■akazuki0117-netizen

### (1) アイデア名

とうけいクエスト（仮）— 算数が分かれば分かる、小中学生のための統計の学び場
Progate のように、各単元を「**見る（動画かスライド）→ 基礎（練習課題）→ 発展（あなたの周りのデータで挑戦してみよう！）**」で進む。発展では、自分の町の本物のデータや、自分で集めたデータでグラフを作る。

### 解決する課題

- 公的な統計の学習サイトは、内容はしっかりしているが、**読み物中心で硬く**、小中学生が自分から続けて使う形になっていない
- 学校の「データの活用」は教科書で習うが、**自分の町や生活のデータで試す場がない**
- 先生は忙しく、統計の授業のための教材を作る時間がない

### 既存プロダクトの有無

あり。

| 既存 | 中身 | 違い |
|---|---|---|
| なるほど統計学園（総務省統計局） | 小中学生向けの統計学習サイト。クイズや自由研究の進め方もある | **一番の競合**。こちらは「短いスライド＋手を動かす演習＋ゲームで進む＋自分の町のデータ」で差をつける |
| キッズすたっと（統計局） | 小中学生向けの統計データの検索 | 「探す」道具。こちらは「学んで、使う」 |
| とうけいキッズ（経済産業省） | 工業・商業の統計の子ども向けサイト | 分野が狭い |
| データサイエンス・スクール（統計局）、データサイエンス・キッズ（SAS） | 講座・ワークショップ | 対象が高め、イベント型 |
| 統計グラフ全国コンクール | 子どもが統計グラフを作って応募 | 競合ではなく**出口**。「ここで練習 → コンクールに応募」とつなげる |

**差別化は3つ**

1. **算数の言葉だけ**で説明する（学年ごと）
2. **見る → 基礎 → 発展**の3段で、ゲームのように進む（Progate 型）
3. **発展で「あなたの周りのデータ」に挑戦する**：自分の町の本物のオープンデータ（人口・気温・公共施設の数など）と、自分で集めたデータで、グラフ作りや比べっこをする

3 が一番大事。教材だけだと、[勝てるアプリ分析](../../../analysis/kentakodama99/hakkason_app_analyse/reports/勝てるアプリ分析_2026.md)でいう「すでにある情報を並べただけ」になり、UDC が見る「オープンデータの活用」と「地域課題」が弱くなる。

### ペルソナ

- 算数は分かるけど、統計の言葉（平均・中央値・最頻値など）でつまずく小学5・6年生、中学生へ
- 夏休みの自由研究や統計グラフコンクールのテーマを探している子へ
- 「データの活用」の授業で、すぐ使える教材がほしい先生へ

### キャッチコピー

きみの町は、数字で見るとどんな町？（案）

### アプリ概要（30秒でいうと）

小中学生が、各単元で**動画かスライドを見て → 基礎の練習課題を解き → 発展で「あなたの周りのデータで挑戦してみよう！」**と、自分の町のデータや自分で集めたデータでグラフを作る。これをゲームのようにクリアしていくことができる。

### その他アプリ機能

- 1単元の流れ（**見る → 基礎 → 発展**）
  1. **見る**：動画かスライド（3〜5枚）で考え方を知る。算数の言葉で（例：「いちばん多いのはどれ？＝最頻値」）
  2. **基礎（練習課題）**：用意したデータで、棒グラフを並べ替える・平均を出す・クイズに答える。その場で ○× と解説
  3. **発展（あなたの周りのデータで挑戦してみよう！）**：身近なデータで同じことをやってみる
     - 自分の町のオープンデータ（人口・気温・公共施設の数など。町を選ぶと出てくる）
     - 自分で集めたデータ（クラスの好きな給食、家の1週間の歩数、通学路の車の数など）を入力して、グラフを作る
  4. **クリア**：バッジや経験値。次の単元が開く
- 町を選ぶ（都道府県 → 市区町村。最初に選んだ町のデータで全部の演習が動く）
- 各単元の最初に30秒ほどの「つかみ」のアニメーション（動画はすべての単元には作らない）
- 先生向けの一覧（このレッスンは授業1コマ、学習指導要領のこの単元、という対応表）
- 自由研究・統計グラフコンクールへの橋渡し（テーマの例、作ったグラフの保存）

**子ども向けに Progate から変えるところ**

- 文字を少なく、ふりがなを付けられるようにする
- 演習はタイピングではなく、**タップ・ドラッグ**（グラフの棒を伸ばす、カードを並べる）
- **ログインなし**。進み具合はその人のブラウザにだけ保存する
- クラスで使うときも、先生が配る「クラスのコード」だけ（個人情報を持たない）

### 使うオープンデータ

| データ | 用途 |
|---|---|
| e-Stat（市区町村の人口・世帯など）、統計ダッシュボード | 自分の町のデータ |
| 教育用標準データセット（SSDSE） | 市区町村・都道府県を比べる演習 |
| 気象庁の過去の気象データ | 気温・降水量のグラフの演習 |
| 自治体のオープンデータ（公共施設・図書館・公園など） | 「自分の町にいくつある？」の演習（BODIK などから） |

利用規約・出典の表示は要確認。データは開発時に JSON にしてサイトに置く（API キーをサイトに出さない）。

### 小中学生向けだから成立する理由

学習指導要領に「データの活用」があり、小学校から統計の考え方を習う。一方で、子どもが自分から使える、ゲームのような統計の学び場は少ない。自分の町のデータなら、算数の問題より「自分ごと」になる。

### 課題との紐づき

- 「公的な学習サイトが硬い」に対して、算数の言葉・短いスライド・ゲームのような進み方で解決できる
- 「自分の町のデータで試す場がない」に対して、発展の「あなたの周りのデータで挑戦してみよう！」（町のオープンデータと、自分で集めたデータ）で解決できる
- 「先生が教材を作る時間がない」に対して、授業1コマで使えるレッスンと、学習指導要領との対応表で解決できる

### 期待効果

- 子どもが統計の考え方を、自分の町のデータを通して身につける
- 自由研究や統計グラフコンクールなど、データを使って何かを作る子が増える
- 先生が統計の授業をしやすくなる

数値での効果は要検討（例：レッスンのクリア数、授業での利用数、コンクールへの応募のつながり）。

### 画面イメージ

[`mock/index.html`](mock/index.html)

- 町をえらぶ（モックは仮の3つの町）→ クエストの一覧（ひとつ前の基礎をクリアすると次がひらく）
- 見る：スライド3枚 → 基礎：グラフを見てクイズ（まちがえるとヒント）→ 発展：町のデータのクイズ、または自分で集めたデータを入れるとすぐグラフと最頻値・平均・中央値が出る
- 進み具合とけいけんち（XP）は、ログインなしでブラウザにだけ保存

## 補足

### 市場の広さ

- 小学生は全国で約590万人、中学生は約310万人（学校基本調査。全国の最新値は文部科学省の公表で要確認）
- 統計グラフ全国コンクールの応募は、2025年度（第73回）で**2万775点**。そのうち小学生の部門だけで約6,200点。統計を使って何かを作りたい子・先生は毎年一定数いる
- お金を払う市場ではなく、**学校の授業・自由研究で無料で使われる**ことが価値。続けるなら、自治体の統計課や統計の団体と組むのが現実的

### 実現性・拡張性・将来性

| 観点 | 評価 | 中身 |
|---|---|---|
| 実現性 | ◎ | 静的サイト（Cloudflare Pages）で作れる。データは先に JSON にしておく。12/27 までは「小学5・6年の"データの活用"の数単元＋自分の町のデータで遊ぶ」に絞る |
| 拡張性 | ○ | 単元・学年を足していける（中学の代表値・箱ひげ図、高校まで）。先生向けの授業プランも足せる |
| 将来性 | ○ | 学習指導要領に「データの活用」があるので、学校の需要は続く。ただし公的サイトと競う形なので、自治体・統計の団体と組めるかが鍵 |

### スタディサプリ型ではなく Progate 型にする理由

| | スタディサプリ型 | Progate 型（こちら） |
|---|---|---|
| 学び方 | 講義の動画 → 確認テスト | 動画かスライド → 基礎の練習課題 → 発展（周りのデータで挑戦）→ クリア |
| 作る量 | 動画が中心で重い | スライドと演習の部品を使い回せる |
| 差別化 | 「読む・見る」の既存サイトと近い | 「自分の町のデータで、自分の手で」が自然に入る |
| オープンデータの出番 | 動画の中の例だけ | 演習の材料として主役 |
| 12/27 までの実現性 | △ | ◎ |

### 勝ちパターン・作品タイプ・賞

- 勝ちパターン D（体験・ゲーム）＋「本物のデータで動く」
- 作品タイプ：アプリケーション（学校での授業として広げるならアクティビティでも出せる）

| 賞 | 見込み | 理由 |
|---|---|---|
| **データキッズ賞**（賞金10万円＋Tシャツ） | ◎ | 「子どもたちのデータ利活用やデータ学習に資するアクティビティ・アプリ」が対象で、ど真ん中（最新の要件は要確認） |
| 一般部門の金・銀・銅（教育・政治） | ○ | 重点部門。ただし教材だけだと実用度・挑戦度が弱いので、「自分の町のデータ」が勝負 |
| BODIK賞 | △ | BODIK APPs に登録すれば対象。自治体のオープンデータと相性がいい |

### 気をつけるところ

- **カリキュラムの骨組み**は、学習指導要領（文部科学省）の「データの活用」にする。統計検定を運営しているのは日本統計学会・統計質保証推進協会で、日本統計協会とは別の団体。どの団体の教材も、文章をそのまま写さない（著作権）
- **動画**は Claude が直接動画ファイルを作れるわけではない。アニメーションの HTML や、スライドに音声を付ける形で作る
- **認証**：ID とパスワードでも、パスワードを預かるならサーバーと安全な保存が要り、静的サイトのままにはできない。子どものパスワードの漏えいのリスクもあるので、ログインなしにする
- 「政治」の要素はほぼない。テーマ「教育・政治」には教育だけで入るが、「Politica（政治参画）」とは別の方向なので、11/29 の会議で候補の1つとして並べる
