## ■akazuki0117-netizen

### (1) アイデア名

人生ルート逆算アプリ（仮）
名前の候補：「ミライ逆算」「人生ルートナビ」「オラ、こういう人生送りたいんだ」

### 解決する課題

- 「こういう人生を送りたい」という理想はあるのに、それに必要なお金・仕事・住む場所を、就職や進学を決める前に具体的に考える機会がない
- 社会に出てから「思ったより稼げない」「住みたい街に住めない」「子どもの学費が払えない」と気づいても、もう選び直しにくい
- 学校で金融教育は習うが、自分の人生の数字としてピンとこない
- 制度（児童手当・高校無償化・奨学金・税・自治体の支援）が自分の人生をどう変えるのかが見えず、政治が自分ごとにならない

### 既存プロダクトの有無

あり。銀行・保険会社などのライフプランのシミュレーター、家計簿アプリの将来予測など。違いは次の3つ。

- 「送りたい人生」から**逆算**する（今の収入から積み上げない）
- **公的なオープンデータ**で出す
- **制度によってルートが変わる**のが見える

具体的なサービス名と違いは要調査（[`survey/README.md`](../../../survey/README.md) にためる）。

### ペルソナ

- 就活を前に、業界や会社を「なんとなく」で選ぼうとしている大学3年生へ
- 進路（大学・学部）を考え始めた高校生へ
- 年齢は絞らない（11/21 キックオフの決定どおり）

**場面の例**：港区や世田谷に住みたい大学3年生。「30歳で年収1000万あればいけるだろう」と金融業界に入ったが、思ったより稼げず、30歳で戸建てを買えたのは八王子。通勤に時間がかかり、40歳で子どもを私立に行かせようとしたら学費が払えない ——「思い描いていた人生と違う」を、就活の前に気づけるようにする。

### キャッチコピー

その人生、いくらかかる？ どのルートで行く？（案）

### アプリ概要（30秒でいうと）

20代・30代・40代で「こうなっていたい」条件（住む場所、家、結婚、子どもの進学など）を、物件の条件を選ぶようにポチポチ選ぶと、必要な年収と、そこに届く人生ルート（業界・年収の伸び方・住む場所・時期）を逆算して出すことができる。さらに「この制度があると、このルートはこう変わる」も見られる。

### その他アプリ機能

- 理想の条件をポチポチ選ぶ（年代ごと：住む場所・家の種類・結婚・子どもの人数と進学先・貯金など）
- 必要な年収・お金の逆算（年代ごとに、いつ・いくら要るか）
- 人生ルートの提示（業界・年収帯ごとに、理想にどこまで届くか。届かない場合は、どの条件を変えれば届くか）
- ルートの比較（例：金融業界ルートと IT 業界ルート、世田谷に住むルートと八王子に住むルート）
- 「つまずきポイント」の表示（例：40歳で私立の学費が重なる、通勤時間が長くなる）
- 制度で変わるルート（児童手当・高校無償化・奨学金・税・自治体の支援を入れる・外すで、ルートがどう変わるか）
- （拡張）その制度を拡げる・変えると言っている公約の一覧（政党を同じ形で並べる）

### 使うオープンデータ

| 欲しい数字 | データ |
|---|---|
| 地価・取引価格 | 国土交通省 不動産情報ライブラリ（API あり） |
| 家賃・住まい | 住宅・土地統計調査（e-Stat） |
| 業界・年齢別の年収 | 賃金構造基本統計調査（e-Stat） |
| 会社ごとの平均年収 | EDINET（API あり） |
| 通勤時間 | 国勢調査、公共交通の GTFS（GTFS賞も狙える） |
| 子どもの教育費 | 文部科学省「子供の学習費調査」 |
| 制度 | 児童手当・高校無償化・奨学金などの国の制度、自治体ごとの子育て・住宅の支援（散らばっているので、自分たちで整備する） |

利用規約は要確認。

### 若い世代向けだから成立する理由

人生の大きな分かれ道（進学先・就職先・住む場所）を選ぶ前だからこそ、逆算に意味がある。社会に出たあとでは選び直しにくい。

### 課題との紐づき

- 「理想に必要なお金が分からない」に対して、条件から必要な年収を逆算する機能で解決できる
- 「就職してから気づく」に対して、業界・年収帯ごとのルートの比較とつまずきポイントの表示で、選ぶ前に気づけるようにして解決できる
- 「金融教育がピンとこない」に対して、自分の理想の人生の数字にすることで解決できる
- 「政治が自分ごとにならない」に対して、制度でルートが変わる表示で、政治と自分の人生をつなげて解決できる

### 期待効果

- 進学・就職・住む場所を、理想から逆算して選べるようになる
- 「思っていた人生と違う」を減らす
- 制度や政治を、自分の人生を変えるものとして見るきっかけになる

数値での効果は要検討。

## 補足

### 勝ちパターン・作品タイプ

- パターン A：地価×年収×教育費などを組み合わせた「新しいものさし」（例：その人生に要る年収）
- パターン D：条件を選ぶとルートが出る体験
- 作品タイプ：アプリケーション
- 課題一覧（[`analysis/kazy/課題一覧_若者と政治教育.md`](../../../analysis/kazy/課題一覧_若者と政治教育.md)）との対応：3-⑥「言っても変わらない」（制度で自分の人生が変わるのを見せる）、9-⑤「調べるコストが払えない」（条件を選ぶだけ）。人生設計そのものは一覧の外の課題なので、課題の根拠（数字）を別に集める必要がある

### 政治との関わり方

政治を芯にはせず、政党ではなく「**制度**」として入れる。

- テーマ「教育・政治」には、金融教育・人生設計の教育だけで入る
- 政党・公約を芯にすると、中立性の設計、公約データの整備と更新、未成年の選挙運動の制限（公職選挙法）が重くなる
- 一方、人生設計のシミュレーターは既存のものが多いので、「制度でルートが変わる」を入れて新しさを出す
- 公約とのつなぎは、余力があれば足す拡張にする

### 地域とのつながり

住む場所を条件の1つとして残す。地価・家賃・通勤時間・自治体の支援のデータを使えるので、UDC の「地域課題」と「オープンデータ」に乗れる。

- 制度・公約は、特定の政党に寄らない形で並べる
