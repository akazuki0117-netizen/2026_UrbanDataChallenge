# グラデーションの広場（仮）

■yk2b0yuka-blip

## (1) アイデア名
グラデーションの広場（仮）

## 解決する課題
政治や社会の話は意見の違いが目立ちやすく、知識や自分の考えに自信がないと、身近な人とも話し始めにくい。賛成・反対だけでは迷いや程度の違いも表しにくい。

## 既存プロダクトの有無
[Polis](https://pol.is/home) は、参加者が投稿された意見に賛成・反対などで回答し、意見の傾向を可視化する参加型討議ツール。意見を可視化して対話のきっかけにする点は共通する。本案は、知り合い同士の少人数を最初の利用場面とし、同じ軸上にある考えの幅をスライダーで示し、全員が答えてから一斉に見て話す体験を中心にする。匿名性や比較方法が安全に機能するかは検証が必要。

## ペルソナ
政治や社会の話に関心はあるが、正しい答えが分からず、友人の考えも聞きにくい人へ。まずは知り合い同士で気軽に遊べる場を想定する。

## キャッチコピー
ちがいを見つけて、話してみよう。

## アプリ概要（30秒でいうと）
同じお題に、それぞれがスライダーと任意の短いコメントで回答。全員の回答がそろうと、考えの広がりと匿名のコメントが一斉に現れる。違いを入口に、自分と相手の考えを話せる。

## その他アプリ機能
- 招待コードによるグループ参加と、かわいいアバターの選択。知らない人と参加する入口は将来案。
- スライダーの両端には同じ論点上の異なる考えを置き、「まだ分からない」も選べる。コメントは任意で、短く入力する。
- 回答がそろうまでは他の回答を表示しない。結果は分布とコメントで表示し、誰がどの位置・コメントを選んだかは表示しない。
- 結果を見た後、短い定型リアクションをきっかけに話す。十分なデータが集まれば、グループと全体の傾向を重ねて見る案もある。
- お題に関係する公的統計などを、お題の背景や出典として参照できるようにする案。結果を公的な世論調査と混同しない。

## 使うオープンデータ
候補は、[政府広報オンライン「国民生活に関する世論調査」](https://survey.gov-online.go.jp/)などの公開資料。関心の高いテーマの検討や背景情報の提示に使うことを想定する。実際にどの調査・地域データを採用するか、機械判読性・利用条件と出典表示は今後確認する。参加者の回答をオープンデータとして公開する予定は決めていない。

## 未成年向けだから成立する理由
正解を求めずに考えの幅を示し、発言前に全員の回答をまとめて見る体験は、知識や経験に自信がない人にとって入口になりうる。学校や友人同士での利用も考えられるが、対象を未成年に限定するものではない（11月21日の方針に合わせて幅広く検討）。

## 課題との紐づき
- 意見が二分されると迷いや中間の考えを出しづらい → スライダーと「まだ分からない」で幅を持って回答する。
- 周囲の反応が気になり話し始めにくい → 全員の回答後に一斉公開し、コメントの投稿者を表示しない。
- 考えの違いを見ても話すきっかけがない → 分布・短いコメントと定型リアクションを会話の入口にする。

関連する調査メモ：[若者と政治教育の課題一覧](../../../analysis/kazy/課題一覧_若者と政治教育.md)。少人数や知り合い同士では文章や会話から投稿者を推測できる可能性があり、匿名性を保証するものではない。利用人数の下限、表示範囲、通報・退出、荒らし対策は実装前に検討する。

## 期待効果
自分の意見を表す、他の人の考えの幅に気づく、理由を尋ねるといった行動のきっかけを増やす。話しやすさや他者の視点への気づきは利用者テストで確認する。効果や費用削減額は未検証。
