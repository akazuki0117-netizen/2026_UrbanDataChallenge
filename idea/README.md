## 置き方

- **1案＝1フォルダ**：`idea/<メンバー>/<アイデアの英字名>/README.md`（例：`idea/akazuki0117-netizen/mogi-senkyo/README.md`）
- 書き方は [`template/README.md`](template/README.md) の項目に沿う
- 案を足したら、自分のフォルダの README の一覧に1行足す
- 動くモックは案のフォルダの中に `mock/`（HTML・CSS・JS をファイル分け）で置く
