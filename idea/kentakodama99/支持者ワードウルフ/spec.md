# 支持者ワードウルフ（仮）仕様

ラベル: `ready-for-agent`

## Problem Statement

投票権を持つ前の中高生は、政党ごとの主張の違いを知らない。マニフェストは文章が硬くて読まれず、「どの党も同じようなことを言っている」と感じたまま18歳を迎える。政治の話題を友達と口にする機会もなく、党どうしの違いを自分で比べる経験がない。

## Solution

ワードウルフの仕組みを使ったオンライン対戦ゲーム。ランダムにマッチングした3〜8人に、第51回衆院選で議席を得た党からランダムに選んだ2党を配る。多数派は A党、ウルフ（1〜2人）は B党の「支持者カード」（党名と主な主張3〜4個）を受け取る。全員がアプリ内のボイスで3分間主張しあい、1回の投票で「一人だけ違う支持者」を見抜く。ゲームのあとは振り返り画面で、2つの党の主張と、国会会議録から選んだ実際の国会での発言を出典付きで並べて見せる。ログインは LINE、年齢は13歳以上の自己申告。通報による自動の参加停止と、通報しあった人どうしを二度と同じ部屋にしない仕組みで安全を保つ。審査員が一人で試せるように、録音済みのプレイヤーと遊ぶデモモードを持つ。

## User Stories

### 入口・ログイン

1. 中高生のユーザーとして、LINE アカウントでログインしたい。そうすれば新しく ID やパスワードを作らずに始められる
2. 中高生のユーザーとして、最初に13歳以上であることを申告したい。そうすれば対象年齢のプレイヤーだけで遊べる
3. 16歳未満のユーザーとして、保護者の同意を得たことにチェックしてから始めたい。そうすれば規約に沿って使える
4. 中高生のユーザーとして、名前・アイコン・メールアドレスを取られないと最初に知りたい。そうすれば安心してログインできる
5. 中高生のユーザーとして、ゲームの遊び方を短く知りたい。そうすれば初めてでも参加できる

### マッチング

6. 中高生のユーザーとして、ボタンひとつでランダムマッチングに入りたい。そうすれば友達を集めなくても遊べる
7. 中高生のユーザーとして、いま何人集まっているかを見たい。そうすればあとどれくらい待つかが分かる
8. 中高生のユーザーとして、60秒待っても集まらなければ「集まりませんでした」と知らされて戻りたい。そうすれば延々と待たされない
9. 中高生のユーザーとして、以前に通報しあった人とは同じ部屋にならないでほしい。そうすれば嫌な思いをくり返さない

### お題と支持者カード

10. 中高生のユーザーとして、ゲームの開始時に自分の支持者カード（党名と主な主張3〜4個）を受け取りたい。そうすれば何を主張すればいいかが分かる
11. 中高生のユーザーとして、自分が多数派かウルフかは知らされないでほしい。そうすれば会話から推理する面白さがある
12. 中高生のユーザーとして、カードの各主張に出典リンクが付いていてほしい。そうすれば元のマニフェストを確かめられる
13. 中高生のユーザーとして、支持者カードは役として配られたものだと画面ではっきりしてほしい。そうすれば自分の思想を問われていると感じずに済む

### ボイスでの話し合い

14. 中高生のユーザーとして、同じ部屋の人とアプリ内のボイスで話したい。そうすれば別の通話アプリを使わなくて済む
15. 中高生のユーザーとして、話し合いの残り時間（3分）を見たい。そうすれば時間配分を考えて話せる
16. 中高生のユーザーとして、誰がしゃべっているかを画面で見たい。そうすれば声と人を結び付けられる
17. 中高生のユーザーとして、特定の人の声をミュートしたい。そうすれば聞きたくない声を止められる
18. 中高生のユーザーとして、話し合いの最中も自分の支持者カードを見返したい。そうすれば主張を思い出しながら話せる

### 投票と結果

19. 中高生のユーザーとして、話し合いが終わったら、ウルフだと思う人に1回投票したい。そうすればゲームに決着がつく
20. 中高生のユーザーとして、ウルフが2人の部屋ではそのことを事前に知りたい。そうすれば推理の前提が分かる
21. 中高生のユーザーとして、投票が同数ならウルフの勝ちになると知っておきたい。そうすればルールに納得できる
22. 中高生のユーザーとして、誰がウルフで、どの2党だったかを結果で知りたい。そうすれば推理の答え合わせができる

### 途中で抜けた人

23. 中高生のユーザーとして、ウルフが途中で抜けたら、そのゲームは無効と知らされたい。そうすれば成り立たないゲームを続けなくて済む
24. 中高生のユーザーとして、多数派が抜けても残りが3人以上ならゲームを続けたい。そうすれば一人が抜けただけで台無しにならない

### 振り返り

25. 中高生のユーザーとして、2つの党の主張を並べて見たい。そうすればどこが似ていてどこが違ったかが分かる
26. 中高生のユーザーとして、その党の議員が実際に国会で何と言ったかを読みたい。そうすれば公約と実際の発言を比べられる
27. 中高生のユーザーとして、国会の発言から、前後の文脈（会議録）へ飛びたい。そうすれば切り取りでないことを確かめられる
28. 中高生のユーザーとして、振り返りのあとで、もう一度マッチングに入りたい。そうすれば別の党の組み合わせで遊べる

### 通報と安全

29. 中高生のユーザーとして、ゲーム中やゲームのあとに、同じ部屋の人を通報したい。そうすれば迷惑な人に対処できる
30. 中高生のユーザーとして、24時間以内に別々の3つのゲームから通報された人は、24時間マッチングに入れなくなってほしい。そうすれば迷惑な人が居続けない
31. 中高生のユーザーとして、自分の声が録音・保存されないと知りたい。そうすれば安心して話せる

### デモモード

32. 審査員として、一人でもデモモードで1ゲームを最後まで体験したい。そうすればマッチングの人数がそろわなくても評価できる
33. 審査員として、デモモードでも振り返り画面まで見たい。そうすれば学びの部分を確かめられる

### 中立性

34. 保護者・教員として、対象の政党が「第51回衆院選で議席を得た党」という基準で決まっていると知りたい。そうすれば「なぜこの党がないのか」に説明がつく
35. 保護者・教員として、どの党が多数派・ウルフになるかはランダムだと知りたい。そうすれば特定の党がおとしめられていないと分かる
36. 保護者・教員として、全政党の支持者カードが同じ形式・同じ量だと確かめたい。そうすれば公平性を信頼できる

### 運営（チーム）

37. データ担当として、党・主張・出典URLを構造化データで管理したい。そうすればコードを変えずにデータを直せる
38. データ担当として、AI で下書きした主張を人が全部チェックしてから載せたい。そうすれば AI の誤りや偏りを防げる
39. データ担当として、国会会議録 API で発言を探し、手で選んで静的データに入れたい。そうすれば関係のない発言や切り取りを防げる
40. データ担当として、データがルール（全政党がそろっている、各党の主張が3〜4個、出典必須）を満たしているかを自動で検査したい。そうすれば抜けや偏りを公開前に防げる
41. データ担当として、構造化データを CC BY のオープンデータとして公開したい。そうすれば UDC でデータを作った貢献を示せる

## Implementation Decisions

### 前提

- ハッカソン提出作品。12/27 提出
- スマホブラウザで動く Web アプリ。ホスティングは Cloudflare
- **オンライン対戦だけを作る**（対面で1台を回す方式や、友達どうしの部屋は作らない）
- ボイスは Cloudflare Realtime（SFU）を使う。録音はしない
- ログインは LINE ログイン。保存するのは LINE の内部 ID のハッシュだけ
- データは第51回衆議院議員総選挙（2026年2月8日投開票）の1回分に固定する

### ゲームのルール

- 1部屋3〜8人。3〜5人ならウルフ1人、6〜8人ならウルフ2人
- ウルフが2人のとき、2人は同じ B党で、互いがウルフだとは知らない
- お題の2党はシステムがランダムに選ぶ。対象は第51回衆院選で議席を得たすべての党
- 流れ：配札 → ボイスで話し合い3分 → 投票1回 → 結果 → 振り返り
- ウルフを当てたら多数派の勝ち。当てられなければウルフの勝ち。同数ならウルフの勝ち。逆転勝ちはなし
- ウルフが途中で抜けたらゲームは無効。多数派が抜けても、残りが3人以上なら続ける

### マッチング

- ランダムマッチングだけ。待つのは60秒で、集まらなければ「集まりませんでした」と通知してトップに戻る
- 通報しあった人どうしは、同じ部屋に入れない
- 参加停止中の人はマッチングに入れない

### 安全

- 年齢は13歳以上の自己申告。16歳未満は保護者の同意にチェックしてもらう
- 利用規約とプライバシーポリシーを用意する
- 会話はボイスのみ。テキストチャットや定型文のスタンプは持たない。声を出さない参加は認めない
- 個別のミュートを用意する
- 通報：24時間以内に別々の3人から通報されたら、24時間マッチングに参加停止。1つのゲームからの通報は1件と数える

### モジュール

1. **ゲーム進行**（メインのモジュール）
   - 部屋の人数・プレイヤーの出入り・投票を受け取り、配札・フェーズの切り替え・勝敗・無効を決める状態機械
   - 乱数と時計を外から渡せるようにし、テストで固定できるようにする
2. **マッチング**
   - 待っているプレイヤーを部屋にまとめる。60秒のタイムアウト、通報しあった人どうしの除外、参加停止の確認を受け持つ
3. **通報・参加停止**
   - 通報を記録し、基準を超えた人を停止する。通報しあった組を返す
4. **ボイス**
   - Cloudflare Realtime への接続、ミュート、話している人の表示。ゲーム進行からは「つなぐ／切る」だけを呼ぶ
5. **政党データ**
   - 党、支持者カードの主張、出典URL、振り返り用の国会での発言（会議録へのリンク付き）。リポジトリ内の静的データ
   - データ検査（全党がそろっているか、主張は3〜4個か、出典はあるか）
6. **認証**
   - LINE ログイン、年齢の申告、保護者の同意
7. **デモモード**
   - 録音済みの音声と台本で、ゲーム進行に偽のプレイヤーを入れて1ゲームを再現する

## Testing Decisions

- **よいテストとは**：モジュールの外から見た振る舞いだけを確かめるテスト。内部の状態の持ち方は確かめない
- **ゲーム進行**：乱数と時計を固定して確かめる
  - 人数ごとのウルフの人数（3〜5人なら1人、6〜8人なら2人）
  - 勝敗の判定（当てた／当てられなかった／同数）
  - ウルフが抜けたら無効、多数派が抜けて残りが3人以上なら続行、3人未満なら無効
- **マッチング**：60秒のタイムアウト、通報しあった人どうしを同じ部屋にしないこと、参加停止中の人を入れないこと
- **通報・参加停止**：24時間以内に別々の3つのゲームから通報されたら停止になり、同じゲームからの複数の通報は1件と数えること
- **データ検査**：本番の政党データに対して、CI で毎回確かめる
- **自動テストの対象外**：ボイスの品質。手動で確かめる

## Out of Scope

- 対面で1台を回して遊ぶ方式、部屋のコードで入る友達部屋
- テキストチャット、定型文のスタンプ、聞くだけの参加
- 録音、運営による通報の目視確認
- AI のプレイヤー（デモモードの録音済みプレイヤーは AI ではない）
- ウルフの逆転勝ち（多数派の党名を当て返すルール）、複数回の投票
- 第51回衆院選以外の選挙、地方議会
- 統計データ（e-Stat など）の振り返りへの表示
- 年齢確認サービスとの連携

## Further Notes

- **公職選挙法**：18歳未満の選挙運動は禁止されている。支持者カードは「役」として配るものであり、プレイヤー自身の支持を表すものではないことを画面で明示する
- **データの作り方**：支持者カードの主張は AI で下書きし、人が全部チェックする（ミライの選択の ADR 0002 と同じ方針）。国会での発言は手で選ぶ
- **オープンデータ**：マニフェストは形式としてはオープンデータでないことが多いため、チームで構造化データに起こし CC BY で公開する。国会会議録検索システムの API と合わせて、利用規約は要確認
