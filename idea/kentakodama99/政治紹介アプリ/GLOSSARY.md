# 中高生向け 選挙・政党紹介アプリ

投票権を持つ前の中高生が、選挙に出ている候補者・政党の主張と、それで日本がどう変わるとされているかを知るためのアプリ。

## Language

### 選挙と主張

**選挙**:
アプリが取り上げる、特定の公職選挙ひとつ。
_Avoid_: 投票、イベント

**候補者**:
ある選挙に立候補している人。
_Avoid_: 議員、政治家

**政党**:
候補者が所属する（または推薦を受ける）政治団体。

**主張**:
候補者または政党が公約・マニフェスト等で公式に表明した政策上の立場。主張する側は候補者か政党のどちらか一方で、必ず元資料にたどれ、必ずひとつの政策トピックに属する。
_Avoid_: 意見、考え、公約（元資料そのものを指すときのみ「公約」）

**過去の主張**:
新しい元資料が出たことで置き換えられた主張。消さずに残し、新しい主張と比べられる。訂正とは区別する。

**元資料**:
主張の出典となる公約・マニフェスト・選挙公報など、候補者や政党自身が公開した文書。

**政策トピック**:
主張を分類する、運営があらかじめ決めたテーマ（教育、経済、環境など）。
_Avoid_: カテゴリ、ジャンル、争点

**選挙期間**:
ある選挙について、候補者別・政党別の気になる割合を公開してはならない期間。アプリでその選挙を公開した時点に始まり、投票締め切り時刻に終わる。
_Avoid_: 選挙運動期間、公示期間（法律上の期間とは別物）

**訂正記録**:
公開後の主張やイメージ解説を直したときの、修正箇所・理由・日付の公開記録。最終確認日とともに表示される。

**イメージ解説**:
主張をもとに「日本や中高生の生活がこう変わるとされている」を描いた解説。主張した側の見立てであり、アプリの予測ではないことを常に明示する。
_Avoid_: 予測、未来予想、AI解説

### ユーザーの行動

**気になる**:
ユーザーが主張に付ける関心の印。
_Avoid_: いいね、支持、投票

**ストック**:
ユーザーが「気になる」を付けた主張の手元の一覧。
_Avoid_: お気に入り、ブックマーク

**コメント**:
ユーザーが政策トピックについて書く、他のユーザーも読める短い意見。そのトピックの主張に気になるを付けた人だけが書ける。主張・候補者・政党へのコメントではない。
_Avoid_: 書き込み、レビュー、口コミ

**投票の呼びかけ**:
特定の候補者・政党への投票や当選・落選を求める表現。コメントには載せない。候補者名や政党名を書くこと自体は含まない。
_Avoid_: 選挙運動（法律上の判断と混同しないため）

**振り返り**:
投票締め切り後に見られる、その選挙の結果とユーザーのストック、候補者別・政党別の気になる割合をまとめたもの。

**気になる割合**:
ある範囲（政策トピック、または投票締め切り後の候補者・政党）について、アプリ利用者全体のうち、その範囲の主張に1つ以上気になるを付けた人の割合。回数ではなく人数で数え、常に母数と一緒に示す。中高生の割合とは呼ばない。
_Avoid_: 人気、支持率、得票率
