# 推しセン！ 場合分けの整理

[spec.md](spec.md) のルールを「どの条件のとき、何ができて何が見えるか」で引けるようにまとめたもの。プロトタイプ [PROTOTYPE-oshisen.html](PROTOTYPE-oshisen.html) はこの表のとおりに動く。

各マスの出どころは次の2つ。

- 印なし：spec.md に書いてある
- **（仮）**：spec.md に書いていないので、プロトタイプで仮に決めた。確定ではない

## 1. 場合を分ける条件

| 条件 | 取りうる値 | 何に効くか |
|---|---|---|
| 選挙フェーズ | 平常時 / 公示前 / 選挙期間（公示日〜投票日の前日）/ 投票日当日 / 開票後 | 投稿、シェア、投票の申告、バッジ、応援の割合 |
| 年齢 | 18歳以上 / 18歳未満 | 投稿、シェア、参戦チケット |
| 見る人 | 本人 / 本人以外 | 相性（%）、当日のバッジ |
| 診断 | まだ / 済み | 相性が出るかどうか |
| 推し | いない / いる | 理由・参戦の画面が使えるかどうか |
| 候補者の情報量 | 通常 / 情報少なめ（新人など） | 相性の計算に使う項目の数 |
| 人柄の特徴の根拠 | 発言が1件以上ある / ない | 特徴を表示するかどうか |
| 投稿の内容 | 票の呼びかけ / 他の候補者への言及 / 悪口 / どれでもない | 投稿が通るかどうか |

## 2. フェーズ × 年齢で、できること

### 18歳以上

| フェーズ | 投稿できるもの | 票の呼びかけ | SNSシェア | 投票の申告 | 「託した」バッジが見える人 | 候補者ごとの応援の割合 |
|---|---|---|---|---|---|---|
| 平常時 | 人柄への「好き」だけ | 止める | できない | できない | 推し仲間にも **（仮）** | 出さない |
| 公示前 | 人柄への「好き」だけ | 止める | できない | できない | 推し仲間にも **（仮）** | 出さない |
| 選挙期間 | 「預けたい理由」 | 書ける | できる | できる（期日前投票）**（仮）** | 推し仲間にも **（仮）** | 出さない |
| 投票日当日 | なし（閲覧だけ） | — | できない | できる | 自分だけ | 出さない |
| 開票後 | 人柄への「好き」だけ | 止める | できない | できない **（仮）** | 推し仲間にも **（仮）** | **出す** |

### 18歳未満

フェーズに関係なく同じ。

| できること | できないこと |
|---|---|
| 診断、候補者の人柄と根拠の発言を見る、推しの登録・変更・解除、推し仲間の理由を読む **（仮：下の未決1）**、全員向けの指標を見る | 投稿、SNSシェア、参戦チケット、投票の申告 |

## 3. 投稿が通るかどうか（上から順に判定）

| 順 | 条件 | 結果 | 止めるもの |
|---|---|---|---|
| 1 | 18歳未満、または投票日当日 | 止まる | ルール |
| 2 | 推し以外の候補者・政党の名前が入っている | 止まる（全フェーズ） | AIチェック |
| 3 | 人を傷つける表現が入っている | 止まる（全フェーズ） | AIチェック |
| 4 | 票の呼びかけが入っていて、選挙期間ではない | 止まる | AIチェック |
| 5 | 上のどれでもない | 通る。選挙期間なら「預けたい理由」、それ以外は「好き」として載る | — |

例（推しが青葉さんのとき）：

| 書いた文 | 平常時・公示前・開票後 | 選挙期間 | 投票日当日 |
|---|---|---|---|
| 「正直に答えるところが好き」 | 通る（好き） | 通る（預けたい理由） | 止まる |
| 「青葉さんに投票してください」 | 止まる（票の呼びかけ） | 通る | 止まる |
| 「柊さんより青葉さんのほうが誠実」 | 止まる（他の候補者） | 止まる（他の候補者） | 止まる |

推しと同じ政党の名前は書ける。同じ政党の別の候補者の名前は止まる **（仮）**。

## 5. 画面ごとの出し分け

| 画面 | 条件 | 出るもの |
|---|---|---|
| 診断 | 回答の途中 | 次の質問 |
| 診断 | 全問回答済み | 預けたい人物像、やり直すボタン |
| 推し | 診断がまだ | 診断への案内 |
| 推し | 診断済み | 選挙区の候補者を相性順に表示 |
| 推し（候補者の詳細） | 情報少なめの候補者 | 「情報少なめ」の表示と、相性に使った項目の数 |
| 推し（候補者の詳細） | 無所属 | 箱なし。比例代表は別に考える旨 **（仮）** |
| 推し（候補者の詳細） | 政党に所属 | 箱（政党）と、同じ箱の他の候補者への導線 |
| 理由 | 推しがいない | 推し探しへの案内 |
| 理由 | 推しがいて、投稿できる | タグ、一言の入力欄、推し仲間の声 |
| 理由 | 推しがいて、投稿できない | 理由の説明と、推し仲間の声だけ |
| 参戦 | 推しがいない | 推し探しへの案内 |
| 参戦 | 18歳未満 | 「チケットは18歳から」**（仮）** |
| 参戦 | 18歳以上・平常時 | 「選挙がない時期」の案内 **（仮）** |
| 参戦 | 18歳以上・公示前〜開票後 | 参戦チケットと投票所の案内。申告ボタンは選挙期間と当日だけ押せる |
| みんな | 開票前 | 全員向けの指標と、「開票まで出さない」の説明 |
| みんな | 開票後・推しが当選 | 結果、応援の割合、当選のメッセージ |
| みんな | 開票後・推しが落選 | 結果、応援の割合、「推し活は続けられる」のメッセージ |
| みんな | 開票後・推しがいない | 結果と応援の割合だけ |

## 6. 候補者の情報量による違い

| 場合 | 人柄の特徴 | 相性の計算 |
|---|---|---|
| 通常（現職など） | 根拠の発言がある特徴をすべて表示 | 診断の全項目で計算 |
| 情報少なめ（新人など） | 公約・経歴・演説動画から読み取れた特徴だけ表示。「情報少なめ」を明示 | 分かっている項目だけで計算 **（仮：下の未決2）** |
| 根拠の発言がない特徴 | 表示しない | — |

## 7. 未決のこと

spec.md に書かれていない、または書き方が食い違っている場合。プロトタイプでは右の欄のとおり仮に決めている。

| # | 場合 | 何が決まっていないか | プロトタイプでの仮の扱い |
|---|---|---|---|
| 1 | 18歳未満が推し仲間の理由を読む | ストーリー25は「18歳以上として読みたい」、投稿ルールの表は「閲覧だけ」 | 読める |
| 2 | 情報少なめの候補者の相性 | 少ない項目だけで計算すると高い%が出やすい（例：新人は2項目で93%、現職は5項目で69%） | 分かっている項目だけで計算し、項目数を表示 |
| 3 | 期日前投票をした人のバッジ | 選挙期間中に推し仲間へ見せてよいか | 見える |
| 4 | 選挙期間に書いた「預けたい理由」 | 投票日当日・開票後も表示したままでよいか | 表示したまま |
| 5 | 推しを変えたときの過去の投稿 | 消すか、前の推しの側に残すか | 前の推しの側に残す |
| 6 | 投票の確認 | 自己申告しかない。バッジの意味がそれで足りるか | 自己申告。誰に入れたかは聞かない |
| 7 | 平常時と公示前の違い | 投稿ルールは同じ。違いはリマインドや「選挙が近い」の知らせだけか | 画面の違いは参戦タブの案内文だけ |
| 8 | 開票後のバッジと投票の申告 | 開票後に申告できるか、バッジをいつまで見せるか | 申告はできない。バッジは推し仲間にも見える |
