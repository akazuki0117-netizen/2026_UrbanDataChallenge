# 推しセン！ 機能仕様

> 選挙は「行く」時代から「応援する」時代へ。

## Problem Statement

18〜29歳の若者の多くは、選挙に行かない。理由としてよく言われるのは「自分が1票入れても変わらない」。

ところが同じ若者が、1票の影響がもっと小さい人気投票には熱心に参加する。人気投票では結果を変えるためではなく、その人の**人柄を見て応援したい**から票を入れている。

選挙に足りないのはこの「応援したい」という気持ちだ。若者から見ると、候補者は政策や数字の羅列でしかなく、人柄が見えない。「この人に日本を預けたい」と思える相手がいないから、投票する理由がない。

既存のサービスには次のような問題がある。

- オープンデータ（得票数、政策の一覧）を表示するだけで、気持ちが動かない
- 1票の格差のような数字を見せると、かえって「行っても意味がない」という感覚を強めてしまう
- 人気ランキングを見せると人気投票になり、少数派の推しを持つ人の気持ちを下げる。しかも公職選挙法138条の3（人気投票の公表の禁止）に抵触するおそれがある

## Solution

推しセン！は、候補者の**人柄**から「この人に日本を預けたい」と思える推しを見つけ、応援し、投票日に「推しに託しに行く」までを推し活として体験できるアプリ。

1. **人柄の好みを診断する**：政策ではなく「どんな人に預けたいか」を答える
2. **人柄から推しと出会う**：AIが公開発言（国会の議事録、演説、SNS）から読み取った人柄の特徴をもとに、相性のいい候補者が見つかる。判定には必ず根拠の発言がつく
3. **預けたい理由を言葉にする**：推しポイントタグを選び、一言を添える
4. **推しに託しに行く**：参戦チケット風の画面と投票所の案内で、投票日を「参戦日」にする
5. **推し仲間と見守る**：同じ推しを持つ人と理由を見せ合い、開票日には一緒に当落を見届ける

数字で煽らない。見せるのは「誰が人気か」ではなく「**どこが推されているか**」。

## User Stories

### オンボーディング・価値観診断

1. 選挙に行ったことがない若者として、政治の知識がなくても答えられる質問で始めたい。そうすれば最初の一歩で挫折しない
2. ユーザーとして、「約束を守る人と柔軟に変えられる人、どっちが好き？」のような人柄の好みについての質問に答えたい。そうすれば自分がどんな人に預けたいのかが分かる
3. ユーザーとして、診断の結果を「自分の預けたい人物像」として見たい。そうすれば自分の価値観を言葉にできる
4. ユーザーとして、政策についての質問にも任意で答えたい。そうすれば人柄以外の面からも相性を確かめられる
5. ユーザーとして、住所や選挙区を登録したい。そうすれば自分が実際に投票できる候補者が表示される
6. ユーザーとして、診断をやり直したい。そうすれば考えが変わったときに反映できる
7. 18歳未満のユーザーとして、診断や推しの閲覧はできるようにしたい。そうすれば有権者になる前から推しを見つけられる

### 推しとの出会い

8. ユーザーとして、自分との相性（価値観の一致度、%）が高い候補者を見たい。そうすれば推しの候補が見つかる
9. ユーザーとして、相性の数字は自分にだけ表示してほしい。そうすれば他の人との比べ合いにならない
10. ユーザーとして、候補者の人柄の特徴（例：「質問をはぐらかさない」「データより現場の話が多い」）を見たい。そうすれば政策の羅列ではなく人として知ることができる
11. ユーザーとして、人柄の特徴ごとに元になった発言（議事録、演説、SNS）をリンクで確認したい。そうすればAIの判定が正しいか自分で確かめられる
12. ユーザーとして、新人候補者には「情報少なめ」の表示がほしい。そうすれば情報が少ないことと人柄が薄いことを取り違えずにすむ
13. ユーザーとして、新人候補者についても公約・経歴・演説動画から読み取った人柄を見たい。そうすれば現職だけが有利にならない
14. ユーザーとして、候補者を推しとして登録したい。そうすれば推し活を始められる
15. ユーザーとして、推しの所属政党を「推しのいる箱」として見たい。そうすれば比例代表の投票先も考えられる
16. ユーザーとして、箱（政党）にいる他の候補者の人柄も見たい。そうすれば箱推しができる
17. ユーザーとして、推しを変更・解除したい。そうすれば気持ちが変わったときに反映できる

### 推しポイントと「預けたい理由」

18. ユーザーとして、推しに「誠実さ」「行動力」「聞く力」などの選択式の推しポイントタグをつけたい。そうすれば推しの好きなところを簡単に表現できる
19. ユーザーとして、タグに一言を添えて「預けたい理由」を書きたい。そうすれば自分がなぜこの人を選ぶのかがはっきりする
20. ユーザーとして、推しが推されている理由の内訳（例：誠実さ40%・行動力35%・聞く力25%）を見たい。そうすればみんなが推しのどこを見ているかが分かる
21. ユーザーとして、アプリ全体で「預ける理由」として重視されている人柄の割合を見たい。そうすれば今の社会が何を求めているかが分かる
22. ユーザーとして、自分の選挙区でどの推しポイントが重視されているかの傾向を見たい。そうすれば地域の空気が分かる
23. ユーザーとして、自分の選挙区で若者の声がどれくらい届いているか（例：20代は有権者の12%なのに、投票者の中では6%）を見たい。そうすれば自分が行く意味を格差の話抜きで実感できる
24. ユーザーとして、候補者ごとの人気や応援者数を見せられたくない。そうすれば人気投票に流されず、自分の推しを大切にできる

### 推し仲間との交流

25. 18歳以上のユーザーとして、同じ推しを持つ人の「預けたい理由」を読みたい。そうすれば一体感を感じられる
26. 18歳以上のユーザーとして、自分の「預けたい理由」を推し仲間に公開したい。そうすれば応援の輪に加われる
27. 18歳以上のユーザーとして、公示日から投票日の前日まで、「預けたい理由」をSNSにシェアしたい。そうすれば友達にも推しを知ってもらえる
28. ユーザーとして、公示前や選挙がない時期は、推しの人柄への「好き」だけを投稿したい。そうすれば事前運動の心配をせずに推し活を続けられる
29. ユーザーとして、「投票して」など票を呼びかける表現を公示前に書こうとしたら、AIに止めてほしい。そうすれば知らないうちに法律違反をしなくてすむ
30. ユーザーとして、他の候補者への言及や悪口を含む投稿は止めてほしい。そうすれば推し仲間の場が荒れない
31. 18歳未満のユーザーとして、投稿やシェアはできず、閲覧だけできる状態にしてほしい。そうすれば知らずに選挙運動をしてしまう心配がない
32. ユーザーとして、投票日当日は新しい投稿ができず、閲覧だけになってほしい。そうすれば当日の選挙運動禁止を守れる

### 推しに託しに行く（投票日）

33. ユーザーとして、自分の投票所と期日前投票の場所・時間の案内を見たい。そうすれば迷わず投票に行ける
34. ユーザーとして、期日前投票の開始日や投票日の前日にリマインドがほしい。そうすれば行き忘れない
35. ユーザーとして、「参戦チケット」風の画面がほしい。そうすれば投票日をライブ参戦のように楽しめる
36. ユーザーとして、投票した後に「託した」バッジを受け取りたい。そうすれば推し活の証が残る
37. ユーザーとして、バッジはお金や物と交換できないものにしてほしい。そうすれば買収を疑われない
38. ユーザーとして、投票日当日はバッジを自分にだけ表示してほしい。そうすれば当日の選挙運動にならない

### 開票・振り返り

39. ユーザーとして、開票日に推し仲間と推しの当落を一緒に見守りたい。そうすれば結果発表を推し活のイベントとして楽しめる
40. ユーザーとして、開票が終わった後に、推しセン！ユーザーの応援の割合を振り返りとして見たい。そうすれば自分たちの応援の形を知ることができる
41. ユーザーとして、推しが落選した後も推し活を続けたい。そうすれば次の選挙まで応援できる

### 選挙がない時期

42. ユーザーとして、推しの国会での発言やSNSから更新された人柄の情報を受け取りたい。そうすれば選挙がない時期も推しを知り続けられる
43. ユーザーとして、推しの人柄の特徴に変化があったら通知がほしい。そうすれば推しの成長や変化に気づける
44. ユーザーとして、選挙が近づいたら知らせてほしい。そうすれば普段の推し活から自然に投票につながる

### 運営・中立性

45. 運営者として、政党・候補者から広告やお金を受け取らない。そうすればAIの判定を含めアプリ全体の信頼が保たれる
46. 運営者として、選挙のフェーズ（平常時／公示前／選挙期間／投票日当日／開票後）をシステムで管理したい。そうすればフェーズごとの表示・投稿ルールが自動で切り替わる
47. 運営者として、候補者から人柄判定への異議申し立てを受け付けたい。そうすれば判定の誤りを直せる
48. 運営者として、候補者ごとの人気を表す指標は、開票後まで内部でも外部に出さない。そうすれば人気投票の公表を避けられる

## Implementation Decisions

### 対象

- メインユーザー：選挙に行かない18〜29歳
- 対象の選挙：国政選挙（衆議院選挙・参議院選挙）
- 推す単位：個人推しが入口。比例代表のために、所属政党を「箱推し」として見せる

### モジュール

- **価値観診断**：人柄の好みの質問（必須）と政策の質問（任意）に答えてもらい、ユーザーの「預けたい人物像」を出す
- **人柄プロファイル**：候補者ごとに人柄の特徴を管理する。各特徴は、元の発言（出典の種類、URL、日付、引用部分）を必ず1件以上持つ。根拠のない特徴は表示しない。情報が少ない候補者には「情報少なめ」フラグをつける
- **人柄抽出（AI）**：国会の議事録・演説・SNS・公約・経歴から人柄の特徴を読み取るアダプター。モデルを交換できるようにインターフェースで分ける
- **相性計算**：ユーザーの人物像と候補者の人柄プロファイルから相性（%）を出す。結果は本人にだけ返す
- **推し・箱推し**：推しの登録・解除、所属政党（箱）への導線
- **推しポイント・預けたい理由**：選択式タグ＋一言。タグの内訳を集計する
- **指標の開示ルール**：何をいつ誰に見せるかを一か所で決める（下の表）
- **投稿ルール**：選挙フェーズ・年齢・内容から、投稿・シェアの可否を決める（下の表）
- **投稿チェック（AI）**：票の呼びかけ表現と他の候補者への言及を検出する
- **選挙フェーズ管理**：選挙ごとに 平常時 → 公示前 → 選挙期間（公示日〜前日）→ 投票日当日 → 開票後 を管理する
- **投票ガイド**：投票所・期日前投票の案内、リマインド、参戦チケット、託したバッジ
- **開票見守り**：開票日のイベント、開票後の振り返り
- **推しの更新**：選挙がない時期の発言の取り込み、人柄の変化の通知

### 指標の開示ルール

| 指標 | 見られる人 | 見られる時期 |
|---|---|---|
| 自分との相性（%） | 本人だけ | いつでも |
| 推しが推されている理由の内訳 | 全員 | いつでも |
| アプリ全体の「預ける理由」の割合 | 全員 | いつでも |
| 選挙区の推しポイントの傾向 | 全員 | いつでも |
| 選挙区で若者の声がどれくらい届いているか | 全員 | いつでも |
| 候補者ごとの応援の割合 | 全員 | **開票後だけ** |
| 候補者ごとの応援数・ランキング・当選予想 | 誰も見られない | なし |
| 選挙区ごとの1票の重さの比較 | 誰も見られない | なし |

政党（箱）についても、候補者と同じく人気の割合は開票後まで出さない。

### 投稿ルール

| フェーズ | 18歳以上 | 18歳未満 |
|---|---|---|
| 平常時・公示前 | 人柄への「好き」だけ投稿できる。票の呼びかけはAIが止める | 閲覧だけ |
| 選挙期間（公示日〜投票日の前日） | 「預けたい理由」の投稿・SNSシェアができる | 閲覧だけ（シェアも不可） |
| 投票日当日 | 閲覧だけ。託したバッジは本人にだけ表示 | 閲覧だけ |
| 開票後 | 平常時と同じ | 閲覧だけ |

どのフェーズでも、他の候補者への言及・誹謗中傷は禁止で、AIがチェックする。

### 中立性・収益

- 政党・候補者からの広告やお金は一切受け取らない
- 投票の見返りとして、お金や物と交換できる特典は出さない
- 人柄の特徴には必ず根拠の発言をつけ、候補者からの異議申し立てを受け付ける

## Testing Decisions

### 良いテストとは

- 外から見た振る舞いだけをテストする。「このフェーズでこのユーザーがこの指標を見られるか」「この投稿が通るか」を確かめ、内部の計算方法には依存しない
- 時刻（選挙フェーズ）とAIはテストから差し替えられるようにする

### テストする境界（シーム）

境界はできるだけ上の層に1つだけ置く。

- **アプリのAPI（推しセン！サービス）**：ユーザー（年齢・選挙区）・現在時刻・選挙の日程を与えて、表示内容と投稿の可否を確かめる。時計とAI（人柄抽出・投稿チェック）はこの境界に差し込む偽物（フェイク）で置き換える

この境界で特に厚くテストするもの：

- 指標の開示ルールの表の全マス（とくに、開票前に候補者ごとの割合が絶対に出ないこと）
- 投稿ルールの表の全マス（フェーズ × 年齢）
- 相性（%）が本人以外のリクエストに含まれないこと
- 根拠の発言がない人柄の特徴が表示されないこと

### 既存のテスト

まだコードベースがないので、参考にできる既存のテストはない。

## Out of Scope

- 地方選挙（市区町村・都道府県の議会選挙、首長選挙）
- 候補者本人による人柄情報の入力、運営による取材記事
- ユーザーの自由な口コミ・レビュー
- 候補者ごとの人気ランキング・当選予想・応援数
- 選挙区ごとの1票の重さの比較
- 政党・候補者からの広告や有料掲載
- 投票と引き換えにお金や物と交換できる特典
- ユーザーどうしのメール機能（有権者はメールでの選挙運動ができないため）

## Further Notes

- **法律の確認が必須**：公職選挙法 138条の3（人気投票の公表の禁止）、129条（選挙運動の期間）、137条の2（18歳未満の選挙運動の禁止）、メールでの選挙運動の制限などに関わる。この仕様の設計は公開情報をもとにしたもので、リリース前に選挙法に詳しい弁護士の確認を受けること
- **AIの判定の偏り**：人柄抽出が特定の政党・候補者に有利または不利に偏っていないか、定期的に監査する仕組みを別途検討する
- **新人候補者の公平性**：「情報少なめ」の候補者が相性の計算で不利にならないよう、計算方法を検証する
- **未決のシーム確認**：上のテストの境界（アプリのAPIを1つ）で良いかは、実装に入る前に開発者と確認する
