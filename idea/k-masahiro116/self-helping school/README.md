    キャッチコピー：大人が追いつけない未来を、僕らが先にアップデートする。

    アプリ概要（30秒でいうと）：SNSやAIの進化に大人のルールが追いつかない今、学生自身が校内民主主義でガバナンスを創る生徒会DXアプリです。

    責任ある匿名制の「目安箱」で日常の悩みやデジタル上の課題を集約し、立候補者がその解決策をマニフェストとして提示・選挙を行うことで、人気投票ではない「自分たちの未来を守るルール作り」を実現します。

    その他アプリ機能：キャッチコピーを軸に、認証・権限、目安箱、生徒会選挙、追加機能、非機能要件を整理した表。システム開発・学校現場での運用・セキュリティ面で不足していた要件の補完を含む。

    課題との紐づき：
    ・課題：政治教育が未熟な状態で投票権を得る。
    ・紐付き：生徒会を民主主義のモデルとし、自分の意見が反映されて改善された時の喜びを体験として得られる。
    　投票の強要や悪ふざけによる投票がどんな影響を及ぼすが、実体験として得られる。
    　今の生徒会は所謂「しっかりした人」しか立候補せず、不平も不満も出ない無難な改革しかされないのではないか。
    　反対意見がぶつかるような熱い生徒会で、選挙とは何かを理解する後押しをする。

    期待効果：
    ・政治教育を促す。
    ・情報リテラシーの教育になる。
    ・学生間でガバナンスが難しい技術にルールを設けて対応できる。→ 教師や親の負担が減る。
