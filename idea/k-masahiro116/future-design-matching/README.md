    コンセプト：今の世の中には情報が溢れ、取捨選択の毎日。気づいたら歳をとっていて、死ぬまでにやりたいことも定まっていない。お金がないというだけで、多くのことに悩まされ、ストレスが溜まる日々。

    解決する課題：
    ・学生の内にある漠然とした将来への不安。就職先。将来設計。
    ・政治への関心度。政治と人生設計の間にある関係性への理解度。

    キャッチコピー：あなたの人生、諦めるにはまだ早い。あなたに合わない世界は間違っている。

    アプリ概要（30秒でいうと）：将来やお金に漠然と不安を抱える学生向けの、「AI人生設計 × 政治マッチング」アプリです。

    AIとの対話を通じて「死ぬまでにやりたいこと」や「自分にとっての成功」を言語化し、就職・結婚・貯金などのライフプランを可視化します。さらに、その理想の人生を実現するために、どの政党のマニフェストや政策が最も自分の味方になるかを自動でマッチング。

    「自分の将来設計」を入口にすることで、これまで遠かった政治を『自分事』として考えるきっかけを作ります。

    その他アプリ機能：オンボーディング、AI人生設計、編集・履歴、政治・自治体マッチング、非機能要件を整理した表。項目名の【追加提案】は、元の一覧で追加提案とされていたもの。

    未成年向けだから成立する理由：選挙権を得る前に、自分の人生設計と政治の関わりを考えることで、投票が自分ごとの選択になる。お金の不安だけで将来を決めず、「成功とは何か」を先に言語化するきっかけになる。

    課題との紐づき：
    ・課題：情報が溢れて将来が定まらず、政治が自分の人生とつながって見えない。
    ・紐付き：やりたいことを軸にした人生設計と、マニフェストとのマッチングで、政治を自分の期限や成功の定義に引きつけて考えられる。政治を自分ごとして考えられる。

    期待効果：
    ・「私の人生における成功とは何か」を言語化するきっかけになる。
    ・お金の不安だけで将来を決めず、やりたいことを軸に期限を置ける。
    ・マニフェストを、自分の人生設計との一致・不一致で読めるようになる。
