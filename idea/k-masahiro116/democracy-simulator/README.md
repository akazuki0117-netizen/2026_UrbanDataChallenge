(1)アイデア名：民主主義シミュレータ

    コンセプト：手軽に法律とは何かを学べるツール。試しに法律を定めてみて、国民や議会からどんな反応があるか、事例をもとにシミュレートし、その結果を楽しみながら法律にはどんな影響力があるのかを理解できる。

    解決する課題：
    ・法律が条文の暗記で終わり、自分の生活や社会にどんな影響力があるのかが分からない。
    ・選挙権を得る前に、法律を定めると国民や議会がどう動くかを試す場がない。

    既存プロダクトの有無：あり。コンセプト（手軽に法律を定めて、国民や議会の反応・社会への影響をシミュレートし、楽しみながら学べる）に近い事例を、「教育・主権者教育特化型」と「ゲーム・シミュレーション型」で10件確認した。

    キャッチコピー：生活を支える"法律"は、いったいどんな役にたっているのか。

    アプリ概要（30秒でいうと）：「民主主義シミュレータ」は、法律を「暗記」ではなく「実験」で学べるシミュレーションアプリです。
    「もし宿題を禁止したら？」「消費税を0%にしたら？」——そんな自分のアイデアを法律として提案するだけで、過去の事例をもとに議会の議論や国民のリアルな反応が返ってきます。
    選挙権を得る前の中高生が、ゲーム感覚で試行錯誤しながら「法律が社会や自分の生活に与える影響力」を体感できるツールです。

    その他アプリ機能：
    ・法律案を自分で定める（テーマを選び、条文のたたき台を書く）
    ・過去の事例をもとに、国民と議会の反応をシミュレートする
    ・シミュレーション結果から、その法律が誰にどんな影響を与えるかを読み取る

    使うオープンデータ：未調査

    未成年向けだから成立する理由：選挙で法律を直接は決められない未成年が、投票の前に「法律を定めると何が起きるか」を遊びながら理解できる。法令を調べる道具ではなく、試して反応を見る学習が入口になる。

    課題との紐づき：
    ・課題：法律の中身と、それが社会に及ぼす影響が見えない。
    ・紐付き：自分で法律を定め、事例にもとづく国民・議会の反応を見ることで、法律の影響力を自分の手で確かめられる。

    期待効果：
    ・法律を暗記ではなく、定めたあとに何が起きるかを通して理解できる。
    ・国民や議会の反応の違いから、一つの法律が人によって違う影響を持つことが分かる。
    ・選挙権を得る前に、法律と自分の生活のつながりを考えるきっかけになる。
