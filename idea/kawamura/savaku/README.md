(1)アイデア名：SAVAKU

    コンセプト：日常の不満や違和感、曖昧なことを法律で裁くことができる。SNSの扱い方や学校での関わり合い、不安定な世の中を法律を通して見る。気になった事象を被告に立たせ、自分は検察官の立場で摘発を試みる。弁護や裁判長はAIが代替し、裁判を通して法律や納得感のある落とし所を学べる。

    解決する課題：
    ・日常の不満や違和感、曖昧な出来事が、法律とどう関係するのか分からない。
    ・SNSの扱い方や学校での関わり合いを、法律の言葉で考える場がない。
    ・法律が条文の知識のままで、自分の立場から法を問う体験がない。

    プロトタイプでは、毎回すべての法令を検索せず、e-GovのXML一括ダウンロードから日常・学校・SNSに直結する主要法令（20〜30本）を抜き、RAGに格納する。

    ・SNS・ネット：刑法（名誉毀損・侮辱・脅迫）、情報流通プラットフォーム対処法（旧プロバイダ責任制限法）、著作権法、不正アクセス禁止法
    ・学校・日常：日本国憲法、民法（不法行為）、軽犯罪法、いじめ防止対策推進法、児童福祉法
    ・バイト・消費：労働基準法、特定商取引法、景品表示法（ステマ規制など）

    未成年向けだから成立する理由：選挙で法律を決められない未成年が、SNSや学校など自分の日常の違和感を裁く側に立つ。大人向けの法律相談ではなく、法律を自分の出来事から学ぶ入口になる。

    課題との紐づき：
    ・課題：日常の違和感と、法律がつながっていない。法律に対し問題意識を持てていない。
    ・紐付き：事象を被告に立て、検察官として摘発し、AIの弁護と裁判を経ることで、法律を裁判のプロセスから学べる。

    期待効果：
    ・曖昧な不満を、法律の論点として言語化できる。
    ・検察・弁護・裁判の役割の違いを、自分の事件を通して理解できる。
    ・SNSや学校の出来事を、法律の観点から見直すきっかけになる。
