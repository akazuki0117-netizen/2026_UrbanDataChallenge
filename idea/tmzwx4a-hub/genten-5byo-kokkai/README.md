# 切り抜きの時代に、原典を。
## 若者の政治の入口「ショート動画」を、正しく使える入口にする2つのサービス

- **案A　ゲンテン**：切り抜き照合サービス（その15秒の「前後」を、公式記録から見せる）
- **案B　5秒コッカイ**：政治版「5秒インフルエンサー」（公式記録から、出典つきショート動画を自動生成する）

---

## 1. エグゼクティブサマリー

若者は、ショート動画をきっかけに政治に触れ始めています。2025年参院選では、YouTube上の関連動画の再生回数が17億回を超えました。一方で、ショート動画、とくに第三者がつくる「切り抜き動画」は、前後の文脈が落ちること、おすすめ表示によって同じ立場の動画ばかりが流れてくることが、見ている本人には見えません。

本企画は、ショート動画を否定するのではなく、**「同じ器（ショート動画）で、中身を公式の一次情報にする」**ことを狙います。

| | 案A　ゲンテン | 案B　5秒コッカイ |
|---|---|---|
| ひとことで | 切り抜きの「前後3分」を見せる | 公式記録から出典つきショートをつくる |
| 役割 | 守り（流れてきた動画を確かめる） | 攻め（確かな動画をこちらから流す） |
| 主な利用者 | 中高生・大学生・新有権者、先生 | 選管・議会・メディア、学校 |
| 使うデータ | 国会会議録API、地方議会会議録 | 国会会議録API、参議院の議員別賛否 |
| 中立性の考え方 | 「悪質」と判定せず、原典を並べるだけ | 全員の賛否・各党の主張を同じ形式・同じ秒数で並べる |

2つの案は同じ「発言データベース」を共有し、案Bでつくった動画には必ず案Aの「原典ページ」へのリンクが付きます。

---

## 2. 背景：若者の政治への入口は、すでにショート動画になっている

### 2-1. 若者の投票と政治への効力感は低いまま
- 2026年2月の衆院選の投票率は、全体56.26%に対し、10歳代43.45%、20歳代39.01%。
- 同じ選挙で18歳は51.47%、19歳は35.20%。高校で主権者教育を受けた直後の18歳から、1年で大きく下がる「19歳の壁」がある。
- 「自分の行動で国や社会を変えられる」と答えた日本の若者は26.9%で、6か国中最下位（日本財団「18歳意識調査」2022年）。

### 2-2. 一方で、ショート動画は「入口」として機能している
- 2025年参院選では、YouTube上の関連動画の再生回数が、前年の衆院選や都知事選を大きく上回る17億回超に達した。
- 政党自身も、縦型のショートドラマやアニメ動画で若者向けの発信を強めている。

### 2-3. ただし、その入口には「見えない偏り」がある
- **文脈が落ちる**：第三者が動画の一部を切り抜いて投稿し、それを見たり「いいね」を押したりすると、関連する別の動画がおすすめに表示される。本人は「自分で選んで見ている」つもりのまま、特定の候補者の情報ばかりに触れることになる。
- **公式情報の空白**：選挙期間中は報道機関が公平性に配慮して報道量を抑えがちで「ニュースの空白」が生まれ、出所や検証が不十分なコンテンツが目立ちやすい（2024年兵庫県知事選の分析より）。
- **短時間で決めている**：東京の有権者調査では、投票者の約2割が投票先を選ぶのに全く時間をかけていない。
- **投票先が動く**：2025年参院選で、TikTokから政治情報をある程度得ていた層の46.2%が選挙期間中に投票先を変えた（全く得なかった層は24.5%）。

### 2-4. 学校だけでは埋められない
- 先生は政治的中立性への配慮から、現実の政治的課題を扱うことに萎縮しがちで、模擬投票も「架空の市長選挙」などが中心になっている。
- 「この切り抜きは偏っているか」を先生が判断して教えることは、中立性の点からさらに難しい。

---

## 3. 解決したい課題

1. **文脈の欠落**：切り抜き動画を見た人が、元の発言の前後（何を聞かれて、どう答えたのか）を確かめる手段がない。
2. **一次情報の届かなさ**：国会の会議録や議員の賛否は公開されているが、若者が見る形式（縦型の短い動画）になっていない。
3. **中立性のジレンマ**：「この動画は偏っている」と判定すると、判定した側が政治的な立場をとってしまう。そのため学校も行政も手を出しにくい。

---

## 4. コンセプト：「判定しない。原典を、同じ器で届ける。」

- ショート動画をやめさせるのではなく、**ショート動画と同じ形式・同じ手軽さで一次情報に触れられる**ようにする。
- 運営側は真偽や良し悪しを判定しない。**公式記録をそのまま、同じ条件で並べる**ことに徹する。
- 米国のニュース比較アプリGround Newsも、「真実の判定者になるのではなく、報道を直接比べることで誇張や言い逃れを浮かび上がらせる」という方針をとっている。本企画はこの考え方を、ニュース記事ではなく政治家の発言と採決に適用する。

## 5. 案A　ゲンテン（切り抜き照合）

### 5-1. 概要
ショート動画のURLを貼る（またはスマホの共有ボタンから送る）と、動画内の発言を文字起こしして国会会議録と照合し、**元の質疑の前後、発言者、日付、会議名**を表示する。

### 5-2. 利用シーン
- 高校2年生のAさんは、TikTokで「〇〇大臣、ついに本音」という15秒の動画を見た。共有ボタンからゲンテンに送ると、実際には野党議員の質問に対する答弁の一部で、直前に条件つきの前置きがあったことがわかる。
- 公民の授業で先生が、生徒が見つけた切り抜き動画をゲンテンで照合し、「どこが切られているか」を一緒に確かめる。先生が政治的な判断を示す必要はない。

### 5-3. 主な機能
| 機能 | 内容 |
|---|---|
| 発言照合 | 動画の音声を文字起こしし、国会会議録APIの発言全文とあいまい検索で照合する |
| 前後ビュー | 該当の発言を中心に、直前の質問と直後のやり取りを縦スクロールで表示する |
| 切り抜き位置の表示 | 動画で使われた部分を会議録上でハイライトし、「切られた前後」を色分けする |
| 同じ争点の他の発言 | 同じ会議・同じ法案についての、他党の議員の発言を自動で添える |
| 授業モード | 先生が照合結果をクラスに配信し、生徒が「切り抜きで印象がどう変わったか」を書き込む |

### 5-4. 中立性の設計
- 「悪質」「誤り」などの判定ラベルは付けない。表示するのは原典と、動画で使われた範囲だけ。
- 照合の結果、該当する発言が見つからなかった場合も「見つかりませんでした（国会以外の場での発言の可能性があります）」とだけ表示し、真偽は断定しない。

### 5-5. 限界と今後
- 会議録があるのは国会（と地方議会）の発言のみで、街頭演説やテレビ番組での発言は照合できない。最初は「国会の切り抜き」に対象を絞る。
- 地方議会の会議録へ対象を広げ、地元の議会の切り抜きにも対応する。

## 6. 案B　5秒コッカイ（政治版5秒インフルエンサー）

### 6-1. 着想
都知事杯オープンデータ・ハッカソン2025のファイナリスト作品「5秒インフルエンサー」は、多摩動物公園の更新ニュースとオープンデータから、ショート動画をワンクリックで作るスマホアプリである。**この仕組みを政治の一次情報に適用する。**

### 6-2. 概要
国会会議録と参議院の議員別の賛否データから、**出典つきの縦型ショート動画（15〜30秒）を自動生成する。**

### 6-3. 2つのモード
**① 公式自動配信モード（選管・議会・メディア向け）**
- 例：「今日の参議院｜〇〇法案　賛成120・反対100」。各会派の主張を同じ秒数・同じテンプレートで並べ、最後に元の記録へのQRコードを表示する。
- 毎日の本会議の採決ごとに自動で生成し、公式アカウントから配信できる形で出力する。
- 地方議会版：学校・公園・給食など、子どもの生活に近い議題が多いのに報道がほとんどない地方議会の動きを、地元の若者に届ける。

**② 教室モード「正しい切り抜き職人」（学校向け）**
- 生徒が会議録から自分でショート動画を作る。作る側を体験することで、「この動画も前後が切られているかも」と気づけるようになる。
- 偏った切り抜きの量産を防ぐため、次の制約を組み込む。
  - 切り出せる最小単位は「質問と答弁のセット」とし、途中で切れないようにする
  - 出典の透かしと原典（ゲンテン）へのリンクは消せない
  - 同じ争点について、他の会派の発言も自動で添えられる

### 6-4. つくらないもの
- **政治家の声や顔をAIで生成しない。** 声の再現はそれ自体がディープフェイクになる。字幕・テキスト・図解のみで構成する。
- **国会中継の映像は最初は使わない。** 二次利用の条件が明確ではないため、会議録のテキストのみで構成する。

## 7. 2つの案の連携

```
        国会会議録API・参議院の議員別賛否・地方議会会議録
                          │
                 共通の「発言データベース」
                ┌─────────┴─────────┐
       案A ゲンテン               案B 5秒コッカイ
   （流れてきた動画を確かめる）   （確かな動画をこちらから流す）
                └──── 生成した動画に原典リンク ────┘
```

- 案Bで生成した動画は、すべて案Aの原典ページにつながる。
- 案Aで照合された「よく切り抜かれる発言」は、案Bで前後を含めた公式版の動画として生成する候補になる。

## 8. 使用するオープンデータ

| データ | 提供元 | 形式 | 用途 |
|---|---|---|---|
| 国会会議録検索システム 検索用API | 国立国会図書館 | XML / JSON | 発言の全文・発言者・日付・会議名（案A・B） |
| 本会議投票結果（押しボタン式投票・記名投票） | 参議院 | Webページ | 議員ごとの賛否（案B） |
| 地方議会の会議録 | 各自治体議会 | Web / PDF など | 地方議会版（案A・Bの拡張） |
| 選挙結果・年代別投票率 | 総務省・自治体オープンデータ | CSV など | 効果測定、地域ごとの優先度づけ |
| 政治資金収支報告書データベース（2027年〜） | 総務省 | データベース公開予定 | 将来の拡張（お金の流れのショート化） |

※衆議院は起立採決が多く、議員個人の賛否が残りにくいため、初期の賛否データは参議院を対象とする。

## 9. リスクと対策

| リスク | 対策 |
|---|---|
| 運営が政治的に偏っていると見られる | 判定ラベルを付けない。全会派を同じテンプレート・同じ秒数で表示する。表示ルールを公開する |
| 偏った切り抜きの量産に使われる | 最小単位を質疑のセットにする。出典の透かしと原典リンクを消せないようにする |
| ディープフェイクの懸念 | 声・顔の生成は行わない。テキストと図解のみ |
| 映像の権利 | 初期は会議録テキストのみを使用する |
| 公職選挙法との関係 | 特定候補の当選・落選を目的としない設計とし、選挙期間中の運用は専門家の確認を経て定める |
| 文字起こし・照合の誤り | 照合の一致度を表示し、低い場合は複数の候補を提示する。断定しない |

## 10. 持続性（誰がお金を払うか）

| 顧客 | 提供価値 | 形態 |
|---|---|---|
| 選挙管理委員会・議会事務局 | 若者に届く公式の発信手段。地方議会の「見える化」 | 自治体向けライセンス |
| 学校・教育委員会 | 中立性を保ったまま、現実の政治を扱える教材 | 授業モードの学校ライセンス |
| メディア | 採決や質疑のショート動画を出典つきで素早く作れる | 生成APIの利用料 |
| 個人（中高生・大学生） | 流れてきた動画を確かめられる | 無料 |

## 11. ロードマップ

| 時期 | 内容 |
|---|---|
| 0〜3か月 | 試作：参議院本会議の採決1件ごとに30秒動画を自動生成（案B①）。国会の切り抜き動画を20本集め、会議録と照合できるかを検証（案A） |
| 3〜6か月 | 公開ベータ：共有ボタンからの照合、前後ビュー。1つの自治体の議会・選管と連携し地方議会版を試行 |
| 6〜12か月 | 授業モード（案A）と教室モード（案B②）を高校数校で実証。次の国政選挙に合わせて本格運用 |

---

## 12. 成功指標

- 照合の成功率（国会の切り抜き動画のうち、原典が特定できた割合）
- 生成動画から原典ページへの遷移率
- 授業で使った生徒のうち「切り抜きの前後を確かめようと思う」と答えた割合（使用前後で比較）
- 連携した自治体での10代・20代の投票率の推移（長期指標）
