## 指摘事項

### 指摘1：ショート動画の課題（tmzwx4a-hub の案6）
- 若者の政治への関心の入口はショート動画になっていて、投票先を動かした事例もある。一方で、情報の正しさや文脈が見えず、アルゴリズムで偏る（エコーチェンバー）危険がある
- 案A（切り抜きの照合＝ファクトチェック側）と案B（公式記録からショート動画を作る＝発信側）の2つを出したが、2つにこだわらず、この課題へのアプローチ全体にコメントがほしい
- 発言データベースまでのデータ集め（ETL）は重そう、という指摘に対し、国会会議録は API があるので作り込む必要はない（tmzwx4a-hub）
- 自分で選ぶのではなく、ランダム・網羅的に流れてくるなら、今のショート動画とは違うものになる（Maci-as）
- X のコミュニティノートのような、ガードレールの役割として見られる（tmzwx4a-hub）
- 動画よりコメント欄から情報を得ることも多い。動画は最後まで見ずにコメントを開く（yk2b0yuka-blip）
- 「文脈の分からない動画を見たことで悪い影響がある」というエビデンスがあれば、課題解決と言いやすい（akazuki0117-netizen）

### 指摘2：課題の示し方（tmzwx4a-hub）
- 募集要領は「地域課題の解決」で、課題を明記したうえでの解決策の提案を求めている。面白いだけでは厳しい。**その課題が多くの人に共有されているか**をどう見せるかが大事
- 国にしか変えられない構造的な課題（制度・投票の手続き）と、自分たちで解決できる課題（心理的なハードルを下げるなど）を分けて考えるとよい
- 「選挙に行こう」という呼びかけが逆効果になっている、という X の声が多く、意外で面白い。18歳の投票率は高いのに19歳で一気に下がる（住民票の問題も絡む）点も面白い

### 指摘3：地域課題の捉え方（akazuki0117-netizen）
- 一つの地域だけでなく、日本全体で共通の課題（1票の格差、東京一極集中など）でもよいのではないか。そのほうがターゲットを絞る必要がなく進めやすい

### 指摘4：ターゲット（Maci-as）
- 教育なら先生の課題も大きい。若者向けの政治の課題は既によく知られていて、調べればたくさん出てくるので、若者に縛らないほうが新しいものができそう
