## 決定事項

### 1. 方向性
- **千葉県の学校データ（校則を中心に）を整える**ことから始める。作るアプリは、データが見えてから決める（データ → アプリの逆算）
- 政治のテーマは今回は見送る。テーマは「教育・政治」の教育側で出す
- 管理の手間を増やさないため、**チームとしては1本に絞る**（複数の案を並行しない）

### 2. 成果物の段階
最終的な形は、進み具合で次のどれかにする。まずは①から。

| 段階 | 成果物 | 作品タイプ |
|---|---|---|
| ① | 整えた学校データ（データセットとデータ定義書） | データ |
| ② | そのデータを使って作ったアプリ（「このデータからこんなアプリが作れる。みなさんも使って」と見せる） | アプリケーション |
| ③ | データと、データから気づきを得るダッシュボードをセットにした Web アプリ | アプリケーション |

- API での提供は、今は考えない。まずデータセットを作るところまで
- 偏差値などをサイトからスクレイピングすると利用規約にかかるおそれがあるので、**千葉県などが公開しているデータを使う**

### 推し活と政治についての議論
- 政党が推し活のような手法をとると、ほかの政党も同じ手段で戦うしかなくなり、社会はその方向に進む。その中で使われるサービスを考えるのはヒントになる（tmzwx4a-hub）
- 推し活の政治は良くないと思うが、進むのは分かる。どちらの方向でも、アプリに思想が乗り、チームの立場が問われる（akazuki0117-netizen）
- 立場をとらずにすむ形（例：政治家のグッズを扱うプラットフォーム）なら偏りは出にくい、という案も出た

### 千葉県の校則データの使い道（tmzwx4a-hub の提案から）
- 校則をテキストでしか見られないので、学校ごとの特徴を可視化する
- 学校の特色（雰囲気）を数値で見せる。偏差値だけでない学校の選び方の材料にする
- 統計分析：校則の公開でブラック校則が減ったか（自然実験）。いじめ対策の効果を見た研究の手法がそのまま使えそう
- 中学校 → 高校の進学の流れ（サンキーダイアグラム）
- 自分たちで校則を決めたら、その学校が将来どうなるかを見せるゲーム（Maci-as）
- 気をつける点：学校の可視化は、学校どうしの競争をあおるおそれがある（tmzwx4a-hub）。データは Excel や PDF がばらばらで、データベースの作り方が悩ましい（k-masahiro116）
