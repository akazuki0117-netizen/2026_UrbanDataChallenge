# survey/ — 一次資料・既存サービスの調査

国・自治体・選挙管理委員会の資料や、既存の政治参加・主権者教育のサービスを集める場所。**テーマごとにサブフォルダを分け、各フォルダの `README.md` に要点と出典を書く。**

| フォルダ（作ったら足す） | 中身 |
|---|---|
| `shukensha-kyoiku/` | 主権者教育（文部科学省・総務省・選挙管理委員会の資料、学校の取り組み） |
| `tohyoritsu/` | 投票率（年代別・18〜19歳、国政・地方選挙） |
| `kizon-service/` | 既存のアプリ・サービス（政治・選挙情報、若者の意見表明、模擬選挙など）。**焼き増しを避けるため必ず調べる** |
| `udc-kako/` | UDC の過去の受賞作品（教育・政治のテーマ） |

## 運用ルール

- 資料は URL・取得日・発行元を残す。PDF などの本体を入れるときは、再配布してよいか確かめる
- 既存サービスは「何を・誰に・どう」と、Politica との違いを1行で書く
